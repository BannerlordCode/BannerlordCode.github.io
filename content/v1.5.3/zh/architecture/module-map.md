# 模块地图 / Module Map

> 一次给你三件事：**这个程序集是什么**、**它被文档放在哪个目录**、**你要不要关心它**。
> 分层心智模型见 [SDK 分层概览](../sdk-overview)；本页是查表用的。

## 为什么需要这张表

`bannerlord-1.5.3/` 根目录下有 **68 个 `TaleWorlds.*` 目录**，但文档只有 **19 个 `api/` 子目录**。
两者不是一对一：一个程序集会被按职责拆进多个目录，一个目录也会聚起来自多个程序集。
不先讲清这条对应关系，你在两边找同一个类都会扑空。

对应关系不是拍脑袋定的：`tools/_dir-map-canonical.json` 的 38 条命名空间规则 + 门面规则，
用**最长前缀优先**匹配 1.5.3 真实的 621 个命名空间，得到 19 个桶（`boardgames` 规则存在但无命名空间命中，故为空桶，未建目录）。

### 不面向 mod 的程序集

这些在源码树里存在，但它们要么是构建期代码生成器，要么是第三方/启动器组件。**它们在 1.5.3 源码里可见，
但游戏运行时不让 mod 依赖**。列出来是为了让你在源码树里看到它们时不困惑。

| 程序集 | 是什么 |
|---|---|
| `TaleWorlds.GauntletUI.CodeGenerator` | 构建期 prefab 代码生成器 |
| `TaleWorlds.MountAndBlade.GauntletUI.CodeGenerator` / `.AutoGenerated.0/.1` | 同上，战斗界面部分 |
| `TaleWorlds.MountAndBlade.SaveSystem.CodeGenerator` | 存档字段代码生成器 |
| `TaleWorlds.MountAndBlade.Launcher` / `.Launcher.Library` / `.Launcher.Steam` | 启动器 |
| `TaleWorlds.MountAndBlade.SteamWorkshop` | 创意工坊 CLI 工具 |
| `TaleWorlds.Starter.Library` | 模组开发启动模板 |
| `TaleWorlds.MountAndBlade.DedicatedCustomServer.ClientHelper` | 专用服务器客户端辅助 |
| `GalaxyCSharp` | 脚本引擎桥 |
| `Newtonsoft.Json` / `jose-jwt` / `Steamworks.NET` / `StbSharp` / `System.Management` / `System.Numerics.Vectors` | 第三方依赖（含参考程序集 `mscorlib` / `netstandard`） |
| `ManagedStarter` | 托管层启动入口 |

> **关键区别：源码树 ≠ 运行时可引用。** `bannerlord-1.5.3/` 把启动器、代码生成器、第三方库和
> 参考程序集（`mscorlib` 2 694 个文件、`netstandard`）都收进来了，共 11 487 个 `.cs`。
> 但你编译 mod 时引用的是游戏安装目录下的 DLL，不是这棵源码树。
> 所以上表里「文档目录」为空或被归入 `core-extra` 的第三方命名空间，
> **不等于**它们是 mod 的可用 API。

## 桶 → 程序集 反向索引

只想知道「我要找的类在哪个目录」时用这张：

| api 目录 | 来源程序集 |
|---|---|
| [campaign](../../api/campaign/) | `TaleWorlds.CampaignSystem`（根命名空间） |
| [campaign-ext](../../api/campaign-ext/) | `TaleWorlds.ObjectSystem` + `CampaignSystem` 的行为/组件/对话/议题子域 |
| [mission](../../api/mission/) | `TaleWorlds.MountAndBlade`（3 个门面类） |
| [mission-ext](../../api/mission-ext/) | `TaleWorlds.MountAndBlade`（其余）+ `.CustomBattle` 之外的全部战斗扩展 |
| [custombattle](../../api/custombattle/) | `TaleWorlds.MountAndBlade.CustomBattle` |
| [gui](../../api/gui/) | `TaleWorlds.ScreenSystem` + `.GauntletUI` + `.TwoDimension` + `.Engine.GauntletUI` |
| [viewmodel](../../api/viewmodel/) | 三个 `*ViewModelCollection` 程序集 |
| [engine](../../api/engine/) | `TaleWorlds.Engine` + `.Engine.InputSystem` + `TaleWorlds.Diamond` |
| [core](../../api/core/) | `TaleWorlds.MountAndBlade` 里的 `MBSubModuleBase`、`Module` |
| [core-extra](../../api/core-extra/) | `TaleWorlds.Core` + `.Library` + `.DotNet` + `.LinQuick` + `.Starter` |
| [localization](../../api/localization/) | `TaleWorlds.Localization` |
| [system](../../api/system/) | `TaleWorlds.InputSystem` |
| [modulemanager](../../api/modulemanager/) | `TaleWorlds.ModuleManager` |
| [save-system](../../api/save-system/) | `TaleWorlds.SaveSystem` |
| [network](../../api/network/) | `TaleWorlds.Network` |
| [activitysystem](../../api/activitysystem/) | `TaleWorlds.ActivitySystem` |
| [achievementsystem](../../api/achievementsystem/) | `TaleWorlds.AchievementSystem` |
| [sandbox](../../api/sandbox/) | `SandBox` |
| [storymode](../../api/storymode/) | `StoryMode` |

**两个容易踩的坑**

1. `TaleWorlds.ObjectSystem` 落在 [campaign-ext](../../api/campaign-ext/)，**没有** `objectsystem` 目录。
2. `TaleWorlds.ScreenSystem` 并入 [gui](../../api/gui/)，**没有** `screensystem` 目录。
