v1.3.0 → v1.3.15 changes

New modules (23)

TaleWorlds.Core.ViewModelCollection, TaleWorlds.Diamond(+.AccessProvider.GDK/.GOG/.Steam/.Test), TaleWorlds.DotNet.AutoGenerated, TaleWorlds.Engine.AutoGenerated, TaleWorlds.MountAndBlade.AutoGenerated, TaleWorlds.MountAndBlade.Diamond, TaleWorlds.MountAndBlade.GauntletUI.CodeGenerator, TaleWorlds.MountAndBlade.GauntletUI.Widgets, TaleWorlds.MountAndBlade.Helpers, TaleWorlds.MountAndBlade.Launcher(+.Library/.Steam), TaleWorlds.MountAndBlade.Multiplayer.Test, TaleWorlds.MountAndBlade.SaveSystem.CodeGenerator, TaleWorlds.MountAndBlade.SteamWorkshop, TaleWorlds.MountAndBlade.ViewModelCollection, TaleWorlds.NavigationSystem, TaleWorlds.PlatformService(+.Epic/.GOG/.Steam), TaleWorlds.PlayerServices, TaleWorlds.SaveSystem, TaleWorlds.ScreenSystem, TaleWorlds.ServiceDiscovery.Client, TaleWorlds.Starter.Library, TaleWorlds.TwoDimension.Standalone, TaleWorlds.ObjectSystem

Removed/restructured

  • SandBox(+.GauntletUI/.View/.ViewModelCollection), StoryMode(+...), TaleWorlds.MountAndBlade.GauntletUI, TaleWorlds.MountAndBlade.View, TaleWorlds.GauntletUI.TooltipExtensions are not separately provided in the 1.3.15 source bundle (partly merged into main assemblies or shipped with the game).
  • SaveSystem split out of MountAndBlade into a top-level module.

v1.3.15 → v1.4.5 changes

New modules (14)

  • TaleWorlds.CampaignSystem.FastMode — campaign fast/batch mode
  • TaleWorlds.CampaignSystem.ViewModelCollection.BirthAndDeath — birth & death VMs
  • TaleWorlds.MountAndBlade.CustomBattle — custom battle
  • TaleWorlds.MountAndBlade.DedicatedCustomServer.ClientHelper — dedicated server client
  • TaleWorlds.MountAndBlade.GauntletUI — M&B Gauntlet (standalone)
  • TaleWorlds.MountAndBlade.GauntletUI.AutoGenerated.0 / .1 — generated code (split)
  • TaleWorlds.MountAndBlade.Multiplayer / .GauntletUI / .GauntletUI.AutoGenerated / .View / .ViewModelCollection — multiplayer split out
  • TaleWorlds.MountAndBlade.Platform.PC — PC platform layer
  • TaleWorlds.MountAndBlade.View — M&B View (standalone)

Removed modules (4)

  • TaleWorlds.MountAndBlade.GauntletUI.CodeGenerator
  • TaleWorlds.MountAndBlade.Launcher (.Library/.Steam kept)
  • TaleWorlds.MountAndBlade.SaveSystem.CodeGenerator
  • TaleWorlds.MountAndBlade.SteamWorkshop

Migration advice

  • New mods on v1.3.15: most complete docs and source, stable API.
  • Targeting v1.4.5: multiplayer/View/Gauntlet are now separate assemblies; reference paths change. Gameplay modules (SandBox/StoryMode) source is now available.
  • Migrating from v1.3.0: SaveSystem namespaces/types unchanged, but switch the reference to standalone TaleWorlds.SaveSystem.dll.
