CampaignSystem namespace long tail

Mental Model

This page covers the remaining CampaignSystem sub-namespaces. Each row contains at most five closely related types from one exact namespace; qualified identities and inventory page paths keep coverage auditable. These entries trace official call chains without promoting implementation details to a stable SDK.

Dependencies

  • CampaignEvents and CampaignGameStarter define registration and lifecycle. Persistent changes return to Actions; calculations return to Models.

Source provenance

Identities and page paths come from tools/data/type-inventory.json; implementation provenance follows the version notes to the corresponding managed assembly or bannerlord-1.4.5/Bannerlord.Source/Modules.SandBox. This page does not claim a native-1.3.15 managed source tree.
