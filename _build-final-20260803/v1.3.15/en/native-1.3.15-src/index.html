Note: The source is decompiler output. Names such as FUN_180..., DAT_180..., and LAB_180... are generated by the tooling and are not original TaleWorlds symbols. Confirm behavior through string references, vftables, exports, managed interfaces, and cross-references.

Search Guidance

  1. If you know a managed interface method, start with the [EngineMethod] entry in the Native Reference, then search for the native method name or nearby registration code.
  2. If you know a native type name, search strings such as ftdnNative_string, rglScene, or rglMaterial, then follow nearby vftable writes and constructors.
  3. If you know a function address, confirm it in COMPLETE-FUNCTIONS.md, then search the generated FUN_ name in the decompiled source.
  4. If you have a crash log or diagnostic text, search the literal string first. Examples include Unable to find native module, /nativeTest, and Modules/Native/get_tileset.bat.
  5. For version comparisons, do not treat addresses as stable API. Addresses are only valid for the current v1.3.15 decompiled sample.
