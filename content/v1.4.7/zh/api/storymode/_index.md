# StoryMode — 战役剧情

这个桶装的是 `StoryMode` 这一层：主线战役的剧情怎么被挂上、怎么推进、怎么在教程阶段锁住玩家、以及主线专属的角色创建改写。它不是「战役世界本体」（那在 [campaign](../campaign/)），而是**骑在战役之上的一套剧本**：`CampaignStoryMode` 本身派生自 `Campaign`，把剧情管理器挂到通用战役上。

| 命名空间 | 类型数 | 装的是什么 |
| --- | ---: | --- |
| `StoryMode` | 17 | 剧情入口与状态根（`CampaignStoryMode`、`StoryModeManager`、`StoryModeEvents`）与任务基类 |
| `StoryMode.GameComponents` | 18 | 剧情对通用模型的改写，以及 `CampaignBehaviors`（11 个）里的各阶段行为 |
| `StoryMode.Quests.*` | 40 | 分阶段的任务链：`FirstPhase` / `SecondPhase` / `ThirdPhase` / `TutorialPhase` / `PlayerClanQuests` / `ConspiracyQuests` |
| `StoryMode.GauntletUI.Tutorial` | 69 | 教程阶段的界面控件层（本桶内最大的一族） |
| `StoryMode.ViewModelCollection.*` | 9+ | 剧情界面绑定层（`Missions`、`Map` 等） |

对模组作者来说，这个桶的价值在**钩子与派生点**：想改主线怎么推进，看 `FirstPhaseCampaignBehavior` / `TutorialPhaseCampaignBehavior` 这类阶段行为；想写自己的剧情任务，从 `StoryModeQuestBase` 或 `ConspiracyQuestBase` 派生；想知道「剧情进行到哪一步」，看 `StoryModeEvents` 暴露的节点。

判断一段逻辑该不该在这里：**只属于主线剧本的**（导师、旗帜、阴谋、教程锁）放这里；**任何战役都该有的**（时间推进、事件总线、聚落状态）在 [campaign](../campaign/)；**只活在战斗场景里的**在 [mission](../mission/) 或 [mission-ext](../mission-ext/)。

## 本区页面（9）

| 页面 | 讲的是什么 |
| --- | --- |
| [CampaignStoryMode](./CampaignStoryMode) | 剧情战役的 GameType 入口：把 `StoryModeManager` 挂到通用 `Campaign` 上并在加载阶段驱动剧情对象 |
| [StoryModeManager](./StoryModeManager) | 剧情模式的存档状态根：聚合事件总线、主线剧情、剧情英雄与旗帜效果，提供 `Current` 静态入口 |
| [StoryModeEvents](./StoryModeEvents) | 剧情模式的全局事件总线：把主线阵营选定、教程结束、旗帜收集、阴谋激活等节点暴露成监听器 |
| [StoryModeQuestBase](./StoryModeQuestBase) | 主线剧情的任务基类：固定 `SpecialQuestType.MainStoryline`、隐藏剩余时间，让子类只写剧情 |
| [ConspiracyQuestBase](./ConspiracyQuestBase) | 第二阶段「阴谋」任务的基类：固定 21 天倒计时、失败时扣减阴谋强度 |
| [StoryModeCharacterCreationCampaignBehavior](./StoryModeCharacterCreationCampaignBehavior) | 主线对角色创建流程的改写器：砍掉旗帜与家族命名阶段，重排父母/文化/长相/出生 |
| [FirstPhaseCampaignBehavior](./FirstPhaseCampaignBehavior) | 第一阶段调度行为：为两位导师预约宅邸、按完成顺序串起主线任务链 |
| [TutorialPhaseCampaignBehavior](./TutorialPhaseCampaignBehavior) | 教程阶段总控行为：初始化教程英雄与村庄头人、用对话与菜单锁住玩家交互 |
| [AchievementsCampaignBehavior](./AchievementsCampaignBehavior) | 主线成就收集器：订阅数十个战役事件，把玩家行为折算成 `AchievementManager` 统计值 |

这 9 页分成三层读：**接入层**是 `CampaignStoryMode` + `StoryModeManager` + `StoryModeEvents`（剧情怎么挂上、状态在哪、事件怎么收）；**派生层**是 `StoryModeQuestBase` + `ConspiracyQuestBase`（写自己的剧情任务从这两个基类开始）；**阶段层**是三个 `*CampaignBehavior`（主线/教程/成就分别在哪一阶段做什么）。

- `tools/_verify/types-1.4.7.json` 按命名空间前缀 `StoryMode` 数：**193** 个类型；
- 其中 **180** 个进了缺口队列（`tools/_verify/missing-types-1.4.7-zh.txt`，已过 R1 噪声过滤；其余 13 个被 `GauntletUI.AutoGenerated*` 一类的排除规则滤掉，不出页面）；
