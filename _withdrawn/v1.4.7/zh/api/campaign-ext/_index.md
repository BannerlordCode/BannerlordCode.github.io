# Campaign ext — 战役扩展点：行为、事件、Action、Model

`TaleWorlds.CampaignSystem` 的扩展子命名空间（`CampaignBehaviors`、`GameComponents`、`ComponentInterfaces`、`Conversation`、`Issues`、`PartyBasedVisitables`、`SandBox`）加上 `TaleWorlds.ObjectSystem`。

这是**模组的主战场**。绝大多数战役模组只需要这个目录里的三个类型：`CampaignBehaviorBase`（挂行为）、`CampaignEvents`（监听与触发）、`*Action`（以受控方式改世界）。

`TaleWorlds.ObjectSystem` 在这里而不是新建目录，因为 1.4.5 的 `campaign-ext` 里本来就有 `MBObjectBase` 与 `MBObjectManager`，见 [Core-Extra](../core-extra/) 的对象身份说明。
