# brief · j10-batch（57 页：把正文里的 markdown 链接降级为反引号）

## 任务
57 页在判据 **J10** 上失败（共 **301 条**）。**J10 = markdown 链接只允许出现在【参见族】与【导航】小节里**；出现在正文（`概述` / `心智模型` / `怎么用` / `真实示例` / `风险与边界` 等）里就是 FAIL（政策 #12761 的机械形式）。

## ★ 修法（唯一）：把**正文里**的 markdown 链接**降级为反引号纯文本** —— **保留文字，不删句子**
```
- 见 [ItemObject](../ItemObject) 的说明      ← 现在（正文里，FAIL）
- 见 `ItemObject` 的说明                      ← 改成这样（保留语义，不再是链接）
```

## ★ 允许/禁止的位置（**事实类，不可推导**）
| 位置 | 规则 |
| --- | --- |
| `## 参见`（或其别名：`依赖关系` / `依赖图` / `依赖`） | **允许** markdown 链接 —— **不要动** |
| `## 导航`（判分器认 `导航` / `Navigation` / `Where to Go`） | **允许** —— **不要动** |
| **其余一切小节**（`概述` / `心智模型` / `怎么用` / `真实示例` / `风险与边界` / `跨版本提示` …） | **禁止** markdown 链接 ⇒ 降级为反引号 |

**⚠ 最容易误判的一条**：有些页的 `## 参见` 用的是**别名**（如 `## 依赖关系`）—— **那些节里的链接是合法的，不要动它们**。只降级「除参见族与导航之外」的链接。

## 硬规则
1. **不得为消 J10 而删句子** —— 把链接降级为反引号，**文字全部保留**。
2. **不得动 `## 参见`（含别名）与 `## 导航` 里的任何链接**。
3. **不得改其它任何内容**（散文措辞、引用行号、代码块一律原样）。
4. 不动 `_index.md`；不 `git add`/`commit`；不改 `tools/**`。
5. **禁止 `git commit --amend`**（跨线规则；五线共用一仓，`--amend` 会改写别线提交）。

## 为什么这批比导航批更安全
**降级为反引号【不产生任何引用】** ⇒ **没有「把格式缺陷换成断链」的风险** ⇒ 只需要**结构门禁**，不需要引用白名单。
