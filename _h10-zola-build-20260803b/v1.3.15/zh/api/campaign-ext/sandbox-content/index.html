SandBox 内容家族

SandBox 内容家族

Mental Model

SandBox 是单机内容模块，不是另一套公共 SDK。它的类展示战役 Behavior、菜单、任务、 对话和 GameState 如何组合。v1.4.5 的来源是 Bannerlord.Source/Modules.SandBox； 本页链接的 v1.3.15 页面只确认托管类型名称。Mod 应依赖 CampaignSystem 契约， 把 SandBox 当作实现范例。

Dependencies

  • CampaignGameStarter 注册战役 Behavior 和 Model。
  • Campaign 拥有已加载的战役状态。
  • GameState 与 GameStateManager 拥有屏幕切换生命周期。
  • SandBox / StoryMode / Native 政策 定义边界。
