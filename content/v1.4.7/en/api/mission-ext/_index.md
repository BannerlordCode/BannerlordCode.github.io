# Mission ext — The whole battle implementation surface (the largest directory)

The root `TaleWorlds.MountAndBlade` namespace plus all of its sub-namespaces: 145 namespaces, 1,669 pages. This layer owns "what actually happens in a battle" — `Mission`, `Agent`, `Formation`, `MissionBehavior`, `MissionView`, AI, scene components, spawn logic, scoring.

**Only 5 entry classes were moved out to [Mission](../mission/).** Everything else stays here. When a page under `Mission` points a "related types" row at this directory, that is by design.

Reading order for a battle mod: `Mission` (entry class) → `MissionBehavior` and components here → event callbacks.
