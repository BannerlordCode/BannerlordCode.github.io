```
1. 【阳性对照优先于一切门禁】

3. 【分母没量不报率】「值得做」不能替代「收益多少」。

4. 【探针必须 fail closed】读不到 / 没运行 / 参数错误 与「没发现问题」用不同状态与退出码。

6. 【精确生成标记优先于宽正则】
   真标记只有四个精确自述串：的自动生成类参考 / Auto-generated class reference /

8. 【只对自己负责的文件清单批量替换】禁止对共享桶目录整体 sed/批量写入。

## 11. 🔴 下个会话第一件事：修 anti-fabrication 的泛型正则（lead-6 已定位）

`tools/lib/anti-fabrication.mjs` 的规则 `/\.([A-Za-z_]\w*)\s*</` 把
**所有比较运算的左操作数**当成泛型实参提取：

```
.X < 3          44 处
.X <= 5f        43 处
.X < y - 1 等    18 处
去重后 105 处，分布在 83 个页面，跨 v1.3.0/v1.3.15/v1.4.5，zh 62 / en 21

Clan.Tier < 3                    AccessLimitationReason.md:152
MainParty.Army.Cohesion < 30f    ArmyCohesionStep2Tutorial.md:63
agentToFollow.GetCurrentVelocity().y < 0f    AgentMovementMode.md:68
```

**105 是上界，不是误报数**——`Tier`/`Cohesion`/`Gold`/`Age` 在语料里真实存在，
所以它们**静默通过**。真正的误报是「左操作数在语料里压根没有」的那个子集，**未量**。

**更坏的一层：门禁会诱导错误修复。**
`AgentLastHitInfo.md:33/:72/:110` 的 `ElapsedTime <= 5f` 被当泛型实参提取，
只因它在语料里恰好存在才通过。换个没在语料里出现的属性名就会变成假 FABRICATED，
下一个人会去「修掉」一行**本来正确的**代码。

**收紧方向与已知代价（必须一起定，否则要改两遍正则）**：
```js
当前： /\.([A-Za-z_]\w*)\s*</g
收紧： /\.([A-Za-z_]\w*)\s*<[A-Za-z_][\w.,\[\]?]*>\s*\(/g      // 闭合 > 后紧跟 (
```
代价：会让**泛型方法写法（`CreateState<T>()`、`SyncData<T>()`）完全不被检查**，
而泛型正是 declare-site 的已知盲区（worker-88 那 20 页 115 个 identifier 里 8 个命中）。
**即：用「泛型不再被检查」换「比较不再被误报」。**

**⚠️ 改它需要窗口，不能赶。** `anti-fabrication.mjs` 文件头写明
「shared by all version lanes」。改它会同时改变另外三条内容线此刻正在跑的基线。
```
1. 先只广播不改，让三条线知道「待做，会改变门禁输出」
2. 等在跑的批次交完
3. 再改，改完立刻重跑全量并公布新 baseline
```
先改后说，今天这套「基线 → 过滤 → 对比」的证据链就废了。
