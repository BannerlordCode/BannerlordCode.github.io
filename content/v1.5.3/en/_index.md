# Bannerlord v1.5.3

## Mental Model

Bannerlord v1.5.3 is a **fully sourced** version: unlike v1.3.0 and v1.4.5, this tree ships every
`TaleWorlds.*` assembly as real source (11 487 `.cs` files across 68 `TaleWorlds.*` modules plus the
`SandBox` / `StoryMode` gameplay modules). That is why this version gets a complete API catalog while
the older ones do not — there is nothing to guess at.

Think of the SDK as a stack of assemblies that **only ever depend downward**:

```
   UI        GauntletUI · ScreenSystem · ViewModelCollection
   Mission   MountAndBlade · CustomBattle · Multiplayer
   Campaign  CampaignSystem · ObjectSystem · ActivitySystem
   Foundation Core · Library · DotNet · Localization · InputSystem
   Native    TaleWorlds.Native.dll  (P/Invoke, out of scope for this tree)
```

Everything a mod author normally touches lives in the top three bands. Read
[SDK Overview](./architecture/sdk-overview) for the full map, or jump straight to a subsystem below.

> **Source provenance**
> `bannerlord-1.5.3/` is **ILSpy decompiler output** — 11 398 of 11 487 files carry `// Token: 0x…`
> markers. Signatures are faithful, but formatting is the decompiler's, not the original author's.
> This matters when diffing against 1.4.5: see [Migrating from 1.4.5](./architecture/migration-from-1.4.5)
> before trusting any signature-level difference.

## How to use this version

1. **Start at the big picture.** [SDK Overview](./architecture/sdk-overview) gives the layered map and
   the reading order; [Module Map](./architecture/module-map) is the assembly-level table.
2. **Pick your band.** Find the row above that matches what you are building, then enter that catalog.
3. **Come up for air often.** Every catalog index links back to [API Reference](./api/) and to this page.
4. **Upgrading?** Read [Migrating from 1.4.5](./architecture/migration-from-1.4.5) first — it is
   source-measured and flags which findings you can trust.

        }
    }
}
