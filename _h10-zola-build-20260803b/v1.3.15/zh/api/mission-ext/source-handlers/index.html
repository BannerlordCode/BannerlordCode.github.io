Source Mission Handlers 源码家族

Source Mission Handlers 源码家族

Mental Model

这些类型属于 MountAndBlade 源码模块的 Mission 实现层。Mission 通过 Mission、MissionBehavior 和各种控制器创建并调度它们；它们适合追踪官方 调用顺序，但具体实现可能随游戏版本变化。v1.4.5 的来源是 bannerlord-1.4.5/Bannerlord.Source/Modules.Native 及其 source mission 目录， 下表链接的是库存中的 v1.3.15 托管类型页面。

先读 Mission、MissionBehavior 和 MissionState。控制器不能直接改写战役持久状态；持久变更必须回到 Campaign Action，并在 Mission 结束时释放 Agent、Scene 和计时器引用。

Dependencies

  • Mission 拥有场景生命周期并分发 Mission Behavior 回调。
  • MissionBehavior 是 Mission 实例的扩展点。
  • Agent、Team、Formation 暴露实时战场状态。
  • Actions 仍是战役世界变更的边界。
