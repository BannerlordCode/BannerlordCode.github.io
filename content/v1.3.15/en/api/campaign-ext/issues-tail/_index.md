# Issue long-tail family

## Mental Model

This is the long-tail index for official Issue implementations. IssueManager and Campaign behaviors decide eligibility and refresh; only then do Quest, Dialog, or GameMenu flows run. Conditions read state and consequences perform one mutation.

## Dependencies

- [CampaignGameStarter](../CampaignGameStarter), [CampaignEvents](../CampaignEvents), and [CampaignBehaviorBase](../CampaignBehaviorBase) define registration and lifecycle.
- Issue results return to [QuestBase](../QuestBase), [DialogFlow](../DialogFlow), or [GameMenu](../GameMenu); an Issue is not a world-mutation service.
