<!-- BEGIN CARVE-OUT NOTE -->
> 本桶是战斗类的**完整 API**（`TaleWorlds.MountAndBlade*` / `TaleWorlds.Mission*` 全量）。
> mod 入口类 [Mission](./../mission/Mission)、[Agent](./../mission/Agent)、[Formation](./../mission/Formation) 被单独抽到 [Mission 桶](../mission/)，**预期布局、非重复路由**，一个类型只落盘一次。
