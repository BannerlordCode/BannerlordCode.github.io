# AnchorPoint

**Namespace:** `TaleWorlds.CampaignSystem.Naval`
**Module:** `TaleWorlds.CampaignSystem`
**Type:** `public class AnchorPoint : IInteractablePoint, ITrackableCampaignObject, ITrackableBase`
**Base:** `IInteractablePoint`
**File:** `bin/TaleWorlds.CampaignSystem/TaleWorlds.CampaignSystem.Naval/AnchorPoint.cs`

## Overview

`AnchorPoint` expresses **where a fleet currently sits and where it is sailing** — the anchor of a [MobileParty](../MobileParty), created as `Anchor = new AnchorPoint(this)` and held in the `MobileParty.Anchor` field. It implements three interfaces: `IInteractablePoint` (a clickable spot on the map), `ITrackableCampaignObject` (banner and position for minimap tracking) and `ITrackableBase` (display name).

Of its four saved fields, three are coordinates or a clock (`Position` / `TargetPosition` / `ArrivalTime`) and one is history (`_lastUsedDisembarkPosition`). **`Owner` is the only reference field with no save attribute** — after a load it must be re-bound through `InitializeOnLoad(MobileParty owner)`.

## Mental Model

Read it as **a quadruple of "current position, target position, arrival clock, last disembark spot"**. The core model is the **dual-position semantics**:

- **`Position` is where the fleet is anchored right now.**
- **`TargetPosition` is the anchor it is sailing to.**
- **`ArrivalTime` is the clock.** `IsMovingToPoint` is entirely derived from it: `ArrivalTime != CampaignTime.Zero && !ArrivalTime.IsPast`. **Note that `CampaignTime.Zero` means "not sailing", not "already arrived"** — zero is used as the sentinel.

`CallFleet(Settlement settlement)` is the single business entry point that ties the quadruple together:

```csharp
CampaignTime fleetTravelTimeToSettlement = Campaign.Current.Models.PartyTransitionModel.GetFleetTravelTimeToSettlement(Owner, settlement);
if (fleetTravelTimeToSettlement == CampaignTime.Zero)
{
    SetSettlement(settlement);
    return;
}
ResetPosition();
TargetPosition = settlement.PortPosition;
ArrivalTime = CampaignTime.Now + fleetTravelTimeToSettlement;
```

**Calling a fleet to the settlement it is already at is a teleport** (`SetSettlement` places it immediately); only a cross-settlement call sets a sailing clock. `HourlyTick()` then checks `ArrivalTime.IsPast` each hour, and on a hit runs `SetPosition(TargetPosition)` plus a green message for the main player.

The second anchor is that **`_lastUsedDisembarkPosition` and `Position` mean different things**. `SetSettlement(settlement)` does both `SetPosition(settlement.PortPosition)` and `SetLastUsedDisembarkPosition(settlement.GatePosition)` — **the anchor is at the harbour, the interaction point is at the gate**. And `GetInteractionPosition()` returns `_lastUsedDisembarkPosition`, **not** `Position`. Conflating the two throws the encounter radius calculation off.

The third anchor is that **`Owner` is not serialized**. `AutoGeneratedInstanceCollectObjects` collects only three `CampaignVec2` values and one `CampaignTime` — **`Owner` is absent**. After a load something external must call `InitializeOnLoad(owner)` to re-bind `MobileParty.Anchor`, or `Owner` stays null and `CallFleet`, `HourlyTick`, `GetBanners` and `Name` all NRE.

## Examples

Call a fleet to another port, taking the full sailing path:

```csharp
MobileParty fleet = MobileParty.MainParty;
Settlement target = Settlement.Find("Caes_Imperium");
if (fleet.Anchor != null && target != null)
{
    fleet.Anchor.CallFleet(target);
    Debug.Print("target=" + fleet.Anchor.TargetPosition + " arrival=" + fleet.Anchor.ArrivalTime, 0);
    Debug.Print("moving? " + fleet.Anchor.IsMovingToPoint, 0);
}
```

Find which port the anchor is currently sitting at, using `IsAtSettlement` rather than rolling your own distance check:

```csharp
MobileParty fleet = MobileParty.MainParty;
foreach (Settlement settlement in Settlement.All)
{
    if (fleet.Anchor.IsAtSettlement(settlement))
    {
        Debug.Print("anchored at " + settlement.Name + " interaction pos=" + fleet.Anchor.GetLastUsedDisembarkPosition(), 0);
    }
}
```

Move the anchor manually and confirm tracking registration — `SetPosition` handles `VisualTrackerManager` as a side effect:

```csharp
MobileParty fleet = MobileParty.MainParty;
CampaignVec2 spot = new CampaignVec2(new Vec2(1200f, -300f), isOnLand: false);
fleet.Anchor.SetPosition(spot);
Debug.Print("valid=" + fleet.Anchor.IsValid + " tracked=" + Campaign.Current.VisualTrackerManager.CheckTracked(fleet.Anchor), 0);
```

## Risks and crash boundaries

- **`Owner` is not serialized.** `AutoGeneratedInstanceCollectObjects` collects only three `CampaignVec2` values and one `CampaignTime`. **Something external must call `InitializeOnLoad(owner)` after loading**, otherwise `CallFleet`, `HourlyTick`, `GetBanners` and `Name` all NRE.
- **`IsReady` is always `true`.** A hard-coded constant with no checks. **Treating it as "interaction is possible" gives the wrong answer whenever the anchor is invalid** — the real test is the three-way condition inside `CanPartyInteract`.
- **`CanPartyInteract` needs all three conditions.** `mobileParty.IsMainParty && IsValid && !IsDisabled`, then the distance test `mobileParty.Position.Distance(GetInteractionPosition(mobileParty)) < Campaign.Current.Models.EncounterModel.NeededMaximumLandDistanceForEncounteringMobileParty`. **Only the main player can interact**; AI fleets cannot be clicked.
- **`GetInteractionPosition` returns `CampaignVec2.Invalid` when `IsValid` is false.** Inside `CanPartyInteract` the `IsValid` check short-circuits first so no distance is computed against `Invalid`; but your own calls to it must check `IsValid` first.
- **`Position` and `_lastUsedDisembarkPosition` mean different things.** The first is where the ship is at the harbour, the second where the player disembarks at the gate. `SetSettlement` writes both, but **they legitimately differ** — a harbour and a gate are not the same point.
- **`HourlyTick` is `internal`.** Mods cannot call it. **Sailing settles on an hourly granularity**, so an elapsed `ArrivalTime` leaves the anchor parked for up to an hour.
- **`SetPosition` only tracks for the main player.** It returns early on `if (!Owner.IsMainParty);`, so **an AI fleet's anchor is never registered with `VisualTrackerManager`.**
- **Save field numbers are not contiguous.** `_lastUsedDisembarkPosition` is 4 and `IsDisabled` is 5. **New fields start at 6**, and `AutoGeneratedSaveManager`'s `AutoGeneratedGetMemberValue*` registrations must be kept in sync.
- **`CheckPositionsForMapChangeAndUpdateIfNeeded()` silently rewrites `Position`.** After a map change, an anchor sitting on non-naval terrain is relocated to the nearest reachable sea point via `FindReachablePointAroundPosition(..., 8f, 1f)`. **This method changes your coordinates without telling you.**
- **`OnPartyInteraction` writes three `MobileParty` fields.** It clears `mobileParty.Ai.AiBehaviorInteractable`, writes `TargetPosition` / `MovePoint`, and calls `SetSailAtPosition`. **It is a write into the party's state machine, not a read-only query.**
