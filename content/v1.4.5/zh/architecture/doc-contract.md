# 文档契约 — 仅手写政策与验收标准（v1.4.5）

> **本页是 v1.4.5 文档的最高写作与审查约束。违反即失败。** 任何 agent、脚本或贡献者在撰写类文档正文前都必须先读这份契约。

## 1. 神圣约束 H1–H9（不可协商）

| ID | 规则 | 违反后果 |
|----|------|----------|
| **H1** | **所有业务类文档正文必须手写**（人，或读过源码与调用点的 agent）。文件存在 ≠ 完成。 | 失败 |
| **H2** | **禁止**：仅从签名生成可交付的概述 / 心智模型 / 方法用途 / 示例。 | 失败 |
| **H3** | 每页必须有真实的**心智模型**：是什么、何时用、何时不要用、怎么用、依赖谁、出错会怎样。 | 失败 |
| **H4** | **依赖关联**必须显式（上游 / 下游 / 事件 / Action / Model / 存档）。防崩溃与坏档全靠它。 | 失败 |
| **H5** | 导航是**双向树**：Parent / Sibling / Children / 相关类型。禁止单向死胡同。 | 失败 |
| **H6** | 目标集合内**不得遗漏业务类型**：每个类型有独立手写深页 **或** 手写簇条目。 | 失败 |
| **H7** | 按**功能模块 / 任务**组织，不以 A–Z 字母墙作为唯一入口。 | 失败 |
| **H8** | 示例必须使用真实 API 与真实获取路径。禁止 `service = ...`、`SomeValue`、错误类型名、空的 `// ...`。 | 失败 |
| **H9** | 现有海量 stub **不算完成**。按波次**整页重写**。禁止在壳上 patch 两行充数。 | 失败 |

### 一句话

> **不要签名填充页。不要样板概述。不要假示例。** 正文只来自读源码与调用点。

## 2. 深页 MUST（任一 FAIL = 未完成）

### 2.1 Frontmatter 与元数据

1. Frontmatter：`title`、`description`（有信息量）
2. 元数据：Namespace / Module / Type / Base / 源文件路径

### 2.2 心智模型与职责

3. 一句话职责（去掉类名仍能懂）
4. **心智模型**（必需）：生命周期、谁创建/持有、所在层、何时用 / 何时不要用（含正确替代，如用 `*Action.Apply` 而非直接改字段）

### 2.3 依赖（可点击）

5. 依赖图含真实存在的相对链接：上游、下游、Events / Behaviors / Actions / Models / 存档点

### 2.4 崩溃与存档风险

6. 风险段（该触达时必填）：坏档、错误阶段 tick、Agent 死后引用、ObjectManager 未注册、Behavior 寿命、Model 空替换、UI 线程/生命周期 → **可能导致崩溃或坏档的用法**

### 2.5 成员、示例、导航

7. 成员说明：每个 mod 可见关键成员 = 用途 + 副作用 + 调用时机（可按主题分组；**禁止**纯签名墙当唯一正文）
8. 一两个**真实**示例，含真实获取路径（`Campaign.Current`、`Mission.Current`、事件订阅、SubModule 钩子等）
9. 导航块：`↑ Parent`、`↔ Sibling`、相关类型；相对链接；目标必须存在
10. 英文页与中文同一理解（英文可后置；S 级尽量同步）

---

## 3. 家族簇页 MUST

1. 家族心智模型与存在理由
2. 共同契约与崩溃面
3. **每个类型（或每个公开入口）都有人写的用途句 + 典型时机**
4. 最危险的子集链到独立深页
5. 回链模块索引与路线图

**禁止**簇页只有 `public static void Apply(...)` 签名列表。

---

## 4. 自动拒收清单

| 模式 | 原因 |
|------|------|
| `阅读时先通过属性了解状态` | 样板（英文等价 "understand state via properties first" 同样拒收） |
| 仅概述：「`X` 是 TaleWorlds… 下的公开类型」 / `是 TaleWorlds 公开类型` | 零信息 |
| 示例含 `SomeValue` | 假数据 |
| 示例含 `service = ...` | 假获取 |
| 示例只有 `// ...` | 空 |
| 错误类型名（如 `IIScene`） | 没读源码 |
| 只有签名列表、无「何时调用」 | 签名墙 |
| 无依赖、无风险、无获取方式 | 空壳 |
| 链到不存在页面 | 导航失败 |
| 在 stub 壳上 patch 两行 | 违反 H9 |

## 5. R1 范围与噪声（v1.4.5 权威）

- **权威**：用法语义来自完整 `bannerlord-1.4.5`（`Bannerlord.Source/bin/...`）。核心 API 与 `1.3.15` 的差异在相应页注记。
- **必须覆盖**：约 4.5k Core 业务 public 类型；含 SandBox+Native 的 SP 约 6.1k 量级。
- **噪声**（AutoGenerated、第三方、平台 provider）：清单 + 短总则页，不写假长文，也不静默消失。
- **版本**：一套主手册（本 v1.4.5 子树）+ 注记/S 级 diff。**禁止**为 3 版本各复制空壳森林。
- **语言**：中文主写 → 英文转写同一理解。
- **M0 之前**：禁止大规模刷长尾；枢纽心智模型空着时禁止下层洪泛。

## 6. 工具：禁用 vs 允许

### 6.1 禁用的产品路径（正文生成）

不得用以下（或等价物）产出可交付的类文档正文：

- `generate-class-docs` / `generate-class-docs.mjs`
- `gen-class-ref.mjs` 正文输出
- `batch-gen-stubs` / `batch-gen-stubs.mjs`
- `enhance-stubs` / `enhance-stubs.mjs`
- `regenerate-method-purposes` / `regenerate-method-purposes.mjs`
- `doc-fragments` 正文填充 / `doc-fragments.mjs` 正文路径
- `populate-curated-content` / `populate-curated-content.mjs`
- `bulk-fix-mental-models` / `bulk-fix-mental-models.mjs`
- `curate-class-docs` 正文生成路径
- `improve-stub-quality` / `improve-stub-quality.mjs`
- 任何新的「签名 → 概述/示例/心智模型」生成器

每个禁用脚本现已带硬失败守卫（见 `tools/RETIRED_BODY_GENERATORS.md`）：除非设置 `BANNERLORD_ALLOW_RETIRED_BODY_GEN=1`（仅本地考古，禁止用于产品构建/CI/提交），否则 exit 1。

### 6.2 允许（只读 / 门禁 / 导航）

- inventory / `generate-inventory`
- `audit-links`（`BROKEN_LINKS=0`）
- `audit-doc-quality`（样板 / 空示例 = blocker）
- `handwritten-coverage`
- section-tree / navigation 生成（仅结构）
- 依赖边抽取（仅图/名单，不向 `content/` 写散文）
- `class-version-diff` / `gen-version-pages`（跨版本 API 对比页）
- `gen-llm-txt`

```bash
zola build
node tools/audit-links.mjs
node tools/audit-doc-quality.mjs
node tools/handwritten-coverage.mjs --root content/v1.4.5/zh/api
```

## 7. 链接与格式规则

- 仅相对链接。优先链 section 目录。
- 散文中的泛型：反引号包裹，如 `` `List<Hero>` ``。
- 整页重写 stub；尽量保留 URL。
- 参见：模块索引 + 一个上游枢纽 + 一个下游/相关。
- 术语：战役 Campaign、任务 Mission、行为 Behavior、行动 Action、模型 Model。

---

## 8. 审查流程

1. 检查深页 MUST（§2）或簇页 MUST（§3）
2. 扫描自动拒收（§4）
3. 任一 FAIL → 打回 Author；绝不标记完成
4. 不得用「自动润色」把一行样板换成另一行样板

---

## 9. 成功线

> 模组开发者按任务找到正确模块与类型，理解心智模型与依赖，复制真实示例，知道崩溃/坏档风险；全站树状可回退；业务 public 类型无空壳遗漏；任何抽检都看不到签名灌版假文档。

**Markdown 文件 + §4 命中 = 未完成。**
**禁用工具正文输出 = 未完成。**
**无证据的「覆盖完成」 = 未完成。**
