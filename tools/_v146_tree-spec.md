## 0. 解析顺序（照抄 artifact，未提前 return）

1. 1. excludeNamespaces / excludeSuffixes / sourceTypoNamespaces  -> hard skip, no page, counted separately
1. 2. rules[] -> longest-prefix-wins. Record the matched rule (dirRule) but DO NOT return early.
1. 3. entryPointDirs -> override by exact case-sensitive simple type name. This step runs for EVERY type, including those whose namespace already matched a prefix rule in step 2. If no override matches, keep the step-2 result.
1. 4. defaultDir (core-extra) if step 2 matched nothing AND step 3 has no entry -> also record in unmapped

伪码：

```
function resolve(ns, typeName) {
  if (excluded(ns)) return 'EXCLUDED';                       // step 1
  let dir = longestPrefixMatch(ns); dir = dir || defaultDir; // step 2 - NO early return
  if (entryPointDirs[typeName]) dir = entryPointDirs[typeName]; // step 3 - ALWAYS runs
  return dir; }
```

## 4. 链接层级（照抄 artifact `linkRules`，不硬编码自己那份）

| 场景 | 写法 |
| --- | --- |
| 叶子 → 同桶兄弟 | `../<Name>` |
| 叶子 → 跨桶 | `../../<other-bucket>/<Name>` |
| 叶子 → 区块索引 | `../` |
| 桶 `_index` → 同桶叶子 | `./<Name>` |
| 桶 `_index` → 父索引 | `../` |
| 桶 `_index` → 语言根 | `../../` |
| `api/_index` → 语言根 | `../` |
| 跨版本 | `../ x(popToSiteRoot) / <version> / <lang> / <section> / <Name>. The language segment must match the TARGET tree, not the source. Verified correct: leaf -> ../../../../v1.4.5/zh/architecture/ ; index -> ../../../v1.4.5/zh/architecture/` |

**禁止**（artifact `linkRules.forbidden`）：

- content/ anywhere in an href - repo-root-relative leakage
- a version segment inside a SAME-version link
- ../<bucket>/<Name> from a leaf page - one level short, only reachable as a sibling
- ./<Name> from a leaf page - dot-slash is legal only from a bucket _index.md

`popToSiteRoot`：`pops-to-site-root == number of segments in the page's OWN route. A leaf route v1.4.7/zh/architecture/version-delta/ has 4 segments and needs FOUR '../'; a section-index route v1.4.7/zh/architecture/ has 3 and needs THREE. Same-version links never need this (they stay inside the tree); cross-version links climb to the site root and therefore need the full pop count.`
