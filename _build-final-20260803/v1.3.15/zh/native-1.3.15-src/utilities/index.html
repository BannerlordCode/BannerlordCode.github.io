工具函数 / Utilities

心智模型

先把 工具函数 当作这个子系统的入口或数据节点来理解：先看属性代表什么状态，再看方法允许你做什么。

概述 / Overview

工具模块包含字符串处理、数学运算、日志系统等辅助功能。

The utilities module contains helper functions for string processing, math operations, logging system, etc.
