# MountAndBlade 托管长尾

## Mental Model

本页覆盖 MountAndBlade 托管程序集的长尾身份。Mission、Agent、Formation、网络、UI 和选项类型按 exact namespace 分组，每行最多五个紧密类型。它们是托管调用链的参考，不是把 Native 或内部实现提升为稳定 Mod API。

## Dependencies

- [Mission](../../mission/Mission)、[Formation](../../mission/Formation)、[Team](../../mission/Team)、[GauntletLayer](../../engine/GauntletLayer) 和 [Models](../../campaign-ext/models) 定义托管入口。
- 持久世界变更回到 [Actions](../../campaign-ext/actions-index)；Native provenance 回到 [SandBox/Native policy](../../../architecture/sandbox-native-policy)。

## Source provenance

类型身份和页面路径来自 `tools/data/type-inventory.json`。实现来源按版本说明指向 MountAndBlade 托管程序集或 `bannerlord-1.4.5/Bannerlord.Source/Modules.Native`；本页不声称 Native C++ 导出是 Mod ABI。
