子系统概述

这里是 campaign 目录 的 CampaignBehaviors 子系统。同一命名空间下的类负责相近功能，可从中找到需要的类型后再进入类页查看方法。

实现战役沙盒中的周期性行为、事件监听与全局系统逻辑。
