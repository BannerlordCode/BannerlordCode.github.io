# 架构 / Architecture

v1.5.3 的架构页解决三件事：**先建立大局观**（分层模型）→ **再查清边界**（哪个程序集归哪个桶）→
**最后确认升级代价**（1.4.5 迁到 1.5.3 到底变了什么）。这三页是本版本仅有的、全部已手写的结构性内容。

## 先知道一件事：类型页是有限的

1.5.3 源码里扫描到 **6 824 个非噪声类型**，而本版本目前只有 **27 篇**手写类型深写页
（清单与逐桶缺口见 [版本首页](../)）。`api/<桶>/` 这种目录索引页**尚未撰写**，
所以本目录下的横向链接只指向这三篇架构页与版本首页，不指向任何 API 目录。
缺口数字与逐桶明细以 [版本首页](../) 为准，本页不重复。

## 三页怎么用

| 你现在的状态 | 读哪页 |
|---|---|
| 刚上手，不知道从哪下手 | [SDK 分层概览](./sdk-overview) —— 五层依赖模型、每层负责什么、mod 从哪切入 |
| 知道要做的事，不知道该引哪个程序集 | [模块地图](./module-map) —— 68 个 `TaleWorlds.*` 程序集逐个的职责与归属桶 |
| 从 1.4.5（或更早）升上来 | [从 1.4.5 迁移](./migration-from-1.4.5) —— 删了什么 / 签名变了什么 / 新增了什么，含 provenance 可信度分层 |
