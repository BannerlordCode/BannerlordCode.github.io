How To Use The Address List

  1. Open COMPLETE-FUNCTIONS.md.
  2. Narrow by address prefix, for example FUN_180746 or FUN_180a21.
  3. Search the same function name in TaleWorlds.Native.dll.c.
  4. Inspect nearby strings, globals, vftable writes, and callees.
  5. Return to the managed docs to find the matching [EngineMethod] or [EngineClass] name.

Notes

  • This catalog does not include full function bodies, avoiding large copied chunks of decompiled source.
  • Addresses only apply to the current v1.3.15 sample; other patch versions can move them.
  • Address-range labels are indexing aids and do not mean every function in that range belongs to one subsystem.
  • Use a PE export-table tool to verify export ordinals and names when precision matters.
