```

**关键区分（我前两次栽在这里）**：

> 不能证明**你用的那一条查询**是对的。

## 6.5 🔺 `anti-fabrication` 查不出的那类编造（worker-86 发现，Lead 已复现）

全树 **1,899 页**的示例里写着 `IIXxx`，而源码里只有 `IXxx`（自动生成器给已带 `I` 前缀的接口又加了一个 `I`）。
```
ICampaignOptionData  →  示例里写成 IICampaignOptionData   ← 编译不过
```
涉及 v1.3.0 / v1.4.5 / 多个桶，**横跨全部三条内容线**。你的页重写时示例重写，自然就消除了，不要保留原样。
