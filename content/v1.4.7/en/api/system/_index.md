# System — System layer: input and the managed runtime long tail

`TaleWorlds.InputSystem`, plus the few managed-runtime namespaces the noise gate lets through. Small (20 types / 15 pages in 1.4.7) but important: it is the first stop for keyboard, mouse and gamepad input.

The 1.4.5 tree already had a directory called `system` for this, so the name was reused rather than inventing `inputsystem`.
