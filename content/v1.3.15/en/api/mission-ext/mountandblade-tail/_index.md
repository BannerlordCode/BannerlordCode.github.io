# MountAndBlade managed long tail

## Mental Model

This page covers the MountAndBlade managed-assembly long tail. Mission, Agent, Formation, network, UI, and option types are grouped by exact namespace with at most five closely related names per row. They document managed call chains without promoting Native or internal details to a stable Mod API.

## Dependencies

- [Mission](../../mission/Mission), [Formation](../../mission/Formation), [Team](../../mission/Team), [GauntletLayer](../../engine/GauntletLayer), and [Models](../../campaign-ext/models) define managed entry points.
- Persistent world changes return to [Actions](../../campaign-ext/actions-index); Native provenance returns to [SandBox/Native policy](../../../architecture/sandbox-native-policy).

## Source provenance

Type identities and page paths come from `tools/data/type-inventory.json`. Implementation provenance follows the version notes to the MountAndBlade managed assemblies or `bannerlord-1.4.5/Bannerlord.Source/Modules.Native`; this page does not claim Native C++ exports are a Mod ABI.
