任务系统 / Mission System

任务系统 / Mission System

心智模型

先把 任务系统 当作这个子系统的入口或数据节点来理解：先看属性代表什么状态，再看方法允许你做什么。

概述 / Overview

任务系统管理战斗场景中的实体、导航和寻路。

The mission system manages entities, navigation, and pathfinding in battle scenarios.

Agent

Agent

游戏实体代理。代表战斗中的士兵、玩家等。

Agent::vftable

功能:

  • 移动控制
  • 攻击/防御
  • 生命值管理
  • 动画同步

弹丸。弓箭、投掷物等。
