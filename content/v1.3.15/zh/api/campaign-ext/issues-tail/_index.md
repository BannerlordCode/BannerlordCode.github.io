# Issue 长尾家族

## Mental Model

这些是官方 Issue 实现的长尾索引。IssueManager 和 Campaign Behavior 决定资格与刷新，之后才进入 Quest、Dialog 或 GameMenu；条件只读状态，结果回调才执行一次变更。

## Dependencies

- [CampaignGameStarter](../CampaignGameStarter)、[CampaignEvents](../CampaignEvents)、[CampaignBehaviorBase](../CampaignBehaviorBase) 定义注册与生命周期。
- Issue 结果回到 [QuestBase](../QuestBase)、[DialogFlow](../DialogFlow) 或 [GameMenu](../GameMenu)，不要把 Issue 当作世界变更服务。
