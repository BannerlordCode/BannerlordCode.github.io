# Save system — Save system: type registration and read/write contexts

`TaleWorlds.SaveSystem` and its `Save`, `Load`, `Resolvers` and `Definition` sub-namespaces. Core types: `SaveManager` (static façade), `SaveContext` (write), `LoadContext` (read), `ISaveDriver` (backend), `SaveableTypeDefiner` (type registration).

**Read [Save System](../../architecture/save-system) first.** If your data is only used by one `CampaignBehaviorBase`, `SyncData` is enough and you never need this directory.

Using this directory means allocating your own globally unique type IDs — a collision is silently resolved as another type on load.
