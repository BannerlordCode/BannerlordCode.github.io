1. **原地重写**：只允许修改你被分配的那批文件本身。不新建、不删除、不改名、不移动页面（URL 稳定性）。保留原 H1（`# Vec3`）与文件路径。

7. **依赖链接**：`## 依赖关系` 段（标题就写 `## 依赖关系`），**至少 2 个**指向同仓已存在页面的相对链接。深度写法：

8. **禁止样板句**（整页 grep 0 命中）：
   `SomeValue` / `null; // 替换` / `service = ...` / `从实际子系统 API` / `Get...Implementation` / `阅读时先通过属性了解状态` / `是 TaleWorlds.X 下的公开类型` / `调用 X 对应的操作`
