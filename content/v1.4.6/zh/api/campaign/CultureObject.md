## 概述

`CultureObject` 是战役层中「文化」这一概念的**定义对象**。游戏里每一个可游玩的文化——帝国、斯特吉亚、阿塞莱、巴塔尼亚、库赛特、瓦兰迪亚，以及各势力的叛军文化——在内存中都是它的一个实例。它不保存任何运行时状态：全部数据来自 XML 定义，在战役初始化时由对象系统（`MBObjectManager`）统一加载。

一个 `CultureObject` 回答的问题是「这个文化默认长什么样、默认用什么、默认擅长什么」：

- **默认兵种与角色模板**：基础兵种、精英兵种、民兵、强盗、市民 / 村民及其人生阶段、各类职业 NPC（铁匠、商人、酒馆老板、公证人……），全部以 `CharacterObject` 引用挂接；
- **默认装备名册**：战斗 / 平民 / 潜行 / 决斗 / 婚礼五套 `MBEquipmentRoster`；
- **默认队伍模板**：默认、村民、捕鱼、民兵、叛军、商队、强盗首领、封臣奖励、聚落巡逻（弱 / 中 / 强 / 海军）等 `PartyTemplateObject`；
- **名字库**：男性名、女性名、氏族名三份 `TextObject` 列表，供命名系统给新英雄与氏族起名；
- **特性与政策**：`CultureTrait[]` 文化特性、`FeatObject` 文化 feat、`PolicyObject` 默认政策列表；
- **文化加成与杂项**：民兵加成、繁荣加成、海军系数、棋盘游戏类型、百科文本、战役起始点。

## 心智模型

**一、CultureObject 是「文化的默认配置清单」，不是运行时状态。**
它不保存「现在谁属于这个文化」——那是运行时实例的事。它只保存「这个文化默认用什么」：默认兵种、默认装备、默认队伍模板、默认名字库、默认政策。除 `MilitiaBonus` / `ProsperityBonus` 外，所有属性都是 `private set`，加载后不可改。

**二、定义 → 模板 → 实例，三层分离。**

1. **文化定义层**：`BasicCultureObject`（基类，提供 `Id` / `Name` / `StringId` 等最基础标识）→ `CultureObject`（本层，文化的全部默认值与关联）。这一层是**静态定义**。mod 作者想加自己的文化，就是新增一个 `CultureObject` 定义（XML + 注册进对象系统），而不是在代码里 new 实例。
2. **角色模板层**：`CharacterObject`（派生自 `BasicCharacterObject`）是「角色模板」。本类的 `BasicTroop`、`LordTemplates`、`Villager` 等属性全部指向模板。模板仍是**定义**，不是某一个具体的人。
3. **实例层**：`Hero`、`Settlement`、`Clan`、`Kingdom`、`MobileParty` 都是**运行时实例**，它们通过各自的 `Culture` 属性反向引用某个 `CultureObject`。实例回答「谁属于哪个文化」，定义回答「这个文化是什么」。

**三、引用语义：属性是对象引用，不是内嵌数据。**
`BasicTroop` 是一个 `CharacterObject` 引用，`DefaultBattleEquipmentRoster` 是一个 `MBEquipmentRoster` 引用。XML 里没配时引用为 `null`（例如 `DefaultCharacterCreationBodyProperty` 在属性缺失时直接为 `null`），用前必须判空。

**四、XML 驱动，对象系统托管。**
`Deserialize`（`CultureObject.cs:564`）是类的灵魂：每个 XML 属性 / 子节点映射到一个成员。mod 加文化 = 加 XML 定义，不是写 C#。

**五、两个例外要记住。**
`MilitiaBonus` 与 `ProsperityBonus` 是唯二 `{ get; set; }` 的属性——运行时可改；`Traits`（`CultureTrait[]`）在原版 `Deserialize` 中**不填充**，原版 C# 源码里也没有赋值点，唯一读取方是 `HasTrait`——调用前要判空。

## 怎么用

### 怎么拿到

```csharp
// 通过字符串 id 从对象管理器取（最常用）
CultureObject vlandia = MBObjectManager.Instance.GetObject<CultureObject>("vlandia");

// 遍历所有文化
foreach (CultureObject culture in MBObjectManager.Instance.GetObjectTypeList<CultureObject>())
{
    // 每个文化都是静态定义，可安全只读访问
}

// 从实例反查：聚落 / 氏族 / 王国 / 英雄都持有 Culture 引用
CultureObject cultureOfClan = clan.Culture;
CultureObject cultureOfHero = hero.Culture;
```

### 典型用法

```csharp
// 1) 读取文化的默认装备名册与队伍模板
MBEquipmentRoster battleGear = vlandia.DefaultBattleEquipmentRoster;
PartyTemplateObject patrol = vlandia.SettlementPatrolPartyTemplateModerate;

// 2) 用文化的名字库给新角色起名
TextObject maleName = vlandia.MaleNameList[MBRandom.RandomInt(vlandia.MaleNameList.Count)];

// 3) 判断文化特性与文化 feat
if (vlandia.HasTrait(someCultureTrait)) { /* ... */ }
foreach (FeatObject feat in vlandia.GetCulturalFeats()) { /* ... */ }

// 4) 读取文化加成（这两个属性运行时可写）
int militia = vlandia.MilitiaBonus;
vlandia.ProsperityBonus = 3;   // 唯二可写的属性之一
```

### 坑

```csharp
// 坑 1：CultureObject 是 sealed 且由对象系统托管——不要 new，只能取
// CultureObject c = new CultureObject();  // 编译不过

// 坑 2：除 MilitiaBonus / ProsperityBonus 外全部 private set——运行时只读
// vlandia.NavalFactor = 1f;  // 编译不过

// 坑 3：Traits 在原版 Deserialize 中不填充——HasTrait 前必须判空
if (vlandia.Traits != null && vlandia.HasTrait(someCultureTrait)) { /* ... */ }

// 坑 4：引用属性可能为 null（XML 未配置时）——用前判空
MBBodyProperty bodyProp = vlandia.DefaultCharacterCreationBodyProperty;
if (bodyProp != null) { /* ... */ }

// 坑 5：id 是字符串常量，拼错不会报错，只会拿到 null
CultureObject c = MBObjectManager.Instance.GetObject<CultureObject>("vlandiaa"); // null
```

## 真实示例

**例 1：XML 定义契约。** `Deserialize`（`CultureObject.cs:564`）的输入就是一个 `<culture>` 节点——属性对应标量成员，子节点对应列表成员：

```xml
<culture id="vlandia" name="{=vlandia_name}Vlandia"
          militia_bonus="2" prosperity_bonus="1" naval_factor="0.8"
          basic_troop="vlandia_recruit" elite_basic_troop="vlandia_footman"
          default_party_template="vlandia_party_template"
          default_battle_equipment_roster="vlandia_battle_roster"
          default_character_creation_body_property="vlandia_body_property"
          text="{=vlandia_encyclopedia}..."
          start_point_position_x="0.45" start_point_position_y="0.32"
          board_game_type="Tablut">
  <default_policies>
    <policy id="policy_x" />
  </default_policies>
  <male_names>
    <name text="{=name_1}Alaric" />
  </male_names>
  <female_names>
    <name text="{=name_2}Beatrice" />
  </female_names>
  <clan_names>
    <name text="{=clan_1}von Ragnar" />
  </clan_names>
  <cultural_feats>
    <feat id="feat_x" />
  </cultural_feats>
  <lord_templates>
    <template name="vlandia_lord_a" />
  </lord_templates>
  <caravan_party_templates>
    <template id="vlandia_caravan" />
  </caravan_party_templates>
</culture>
```

**例 2：给新英雄起名。** 命名系统从文化的名字库随机取名字（`Hero.Culture` 见 `Hero.cs:3126`）：

```csharp
CultureObject culture = hero.Culture;
TextObject firstName = culture.MaleNameList[MBRandom.RandomInt(culture.MaleNameList.Count)];
TextObject clanName = culture.ClanNameList[MBRandom.RandomInt(culture.ClanNameList.Count)];
```

**例 3：按聚落强度选巡逻队模板。** 聚落巡逻按强度等级（弱 / 中 / 强）与海岸（海军）选模板：

```csharp
PartyTemplateObject PickPatrolTemplate(CultureObject culture, int strength, bool naval)
{
    if (naval) return culture.SettlementPatrolPartyTemplateNaval;
    return strength switch
    {
        <= 1 => culture.SettlementPatrolPartyTemplateWeak,
        <= 2 => culture.SettlementPatrolPartyTemplateModerate,
        _ => culture.SettlementPatrolPartyTemplateStrong,
    };
}
```

**例 4：新王国安装默认政策。** 王国建立时把该文化的默认政策装上去（`Kingdom.AddPolicy` 见 `Kingdom.cs:1037`）：

```csharp
foreach (PolicyObject policy in kingdom.Culture.DefaultPolicyList)
{
    kingdom.AddPolicy(policy);
}
```

**例 5：遍历文化 feat。** `GetCulturalFeats` 无参调用即返回全部文化 feat：

```csharp
foreach (FeatObject feat in culture.GetCulturalFeats())
{
    // feat 是该文化专属的文化 feat
}
```
