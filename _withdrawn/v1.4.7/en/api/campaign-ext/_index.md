# Campaign ext — Campaign extension points: behaviours, events, Actions, Models

The `TaleWorlds.CampaignSystem` extension sub-namespaces (`CampaignBehaviors`, `GameComponents`, `ComponentInterfaces`, `Conversation`, `Issues`, `PartyBasedVisitables`, `SandBox`) plus `TaleWorlds.ObjectSystem`.

This is **the main battleground for mods**. Most campaign mods need exactly three types from here: `CampaignBehaviorBase` (register behaviour), `CampaignEvents` (listen and raise) and the `*Action` types (change the world in a controlled way).

`TaleWorlds.ObjectSystem` lives here rather than in a new bucket because 1.4.5 already had `MBObjectBase` and `MBObjectManager` under `campaign-ext`.
