# CampaignSystem 子命名空间长尾

## Mental Model

本页覆盖剩余的 CampaignSystem 子命名空间。每行最多五个同一命名空间的紧密类型；完整命名空间和库存页面路径构成可审计身份。它们用于追踪官方调用链，不把内部实现提升为稳定 SDK。

## Dependencies

- [CampaignEvents](../CampaignEvents)、[CampaignGameStarter](../CampaignGameStarter) 定义注册和生命周期。持久变更回到 [Actions](../actions-index)，计算回到 [Models](../models)。

## Source provenance

身份与页面路径来自 `tools/data/type-inventory.json`；实现来源按版本说明指向对应托管程序集或 `bannerlord-1.4.5/Bannerlord.Source/Modules.SandBox`。本页不声称存在 `native-1.3.15` managed source tree。
