# Bannerlord v1.4.5 BannerHelper Wave

**Goal:** Replace the bilingual generated shells for the MountAndBlade `MBHelpers.BannerHelper` with source-backed documentation that explains its banner-effect calculation contract and its distinction from the Campaign `Helpers.BannerHelper`.

**Architecture:** `MBHelpers.BannerHelper` is a narrow static calculation adapter. A combat or agent-stat caller obtains the active `BannerComponent` from `MissionGameModels.Current.BattleBannerBearersModel`, creates or owns a live `FactoredNumber`, and passes both to `AddBannerBonusForBanner`. The helper checks effect identity and applies either an additive base change or an additive factor; it does not own banners, equipment, models, persistence, or the surrounding calculation lifecycle.

**Tech Stack:** Markdown, Zola clean URLs, Bannerlord v1.4.5 decompiled C# source, Node.js handwritten-policy and documentation audits.
