# AcceptCallToWarOfferMapNotification

**命名空间：** `TaleWorlds.CampaignSystem.MapNotificationTypes`

## 概述

`AcceptCallToWarOfferMapNotification` 是「联盟/参战」子系统的**地图通知数据类**。当一个王国向玩家王国发出参战邀请时，引擎创建本通知并加入地图通知列表，玩家点击通知后触发对应的视图模型行为（参见 `AcceptCallToWarOfferNotificationItemVM`）。

它继承自 `InformationData`，本身**只携带数据、不执行逻辑**：三个属性记录「谁发的邀请」（`OfferingKingdom`）、「要打谁」（`KingdomToCallToWarAgainst`）、「何时触发」（`TriggerTime`），两个重写属性驱动 UI 呈现（`TitleText` 显示标题、`SoundEventPath` 播放提示音），`IsValid` 判断通知是否已过期。

mod 开发者通常不需要手动构造它——它由联盟行为在发出邀请时自动创建。但 mod 可以读取通知列表中的实例来做自定义过滤、日志或 UI 增强。

## 心智模型

把这个类想成**一封摆在地图通知栏里的「邀请函」**，而不是一个执行器。它的全部职责是：

1. **记录邀请事实**——`OfferingKingdom`（邀请方）、`KingdomToCallToWarAgainst`（目标）、`TriggerTime`（触发时间）。三者都带 `[SaveableProperty]`，会随存档序列化。
2. **驱动 UI 呈现**——`TitleText` 返回固定的本地化标题 "Accept Call To War Offer"；`SoundEventPath` 返回提示音路径（复用和平邀请的音效）。
3. **管理生命周期**——`IsValid` 在 `TriggerTime` 未过期时返回 `true`，过期后通知自动失效。

两个构造函数各有用途：主构造函数（`AcceptCallToWarOfferMapNotification.cs:51`）由联盟行为调用，自动计算 `TriggerTime = CampaignTime.Now + AllianceModel.DurationForOffers`；次构造函数（`AcceptCallToWarOfferMapNotification.cs:59`）只接收 `TextObject`，供存档反序列化时使用。

`AutoGenerated*` 系列成员（`AcceptCallToWarOfferMapNotification.cs:23`–`:46`）是引擎为存档序列化自动生成的辅助代码，**不是给 mod 用的 API**，mod 不应调用或依赖它们。

### 典型用法

- **过滤或增强通知：** 遍历通知列表，命中后读取 `OfferingKingdom` 与 `KingdomToCallToWarAgainst`，用于自定义 UI 或日志。
- **判断通知是否仍有效：** 调用 `IsValid()` 检查 `TriggerTime` 是否已过期，避免处理失效通知。
- **复用通知模式：** 参照它如何用三个 `[SaveableProperty]` 字段 + 两个重写属性构建最小通知类，在自己的 mod 中创建自定义通知。

### 坑

- **不要手动构造后加入通知列表。** 主构造函数依赖 `Campaign.Current.Models.AllianceModel.DurationForOffers`，在非战役上下文会拿到 null 模型。
- **`IsValid` 过期后不会自动从列表移除。** 需要引擎的通知清理机制处理，mod 不应手动删除。
- **`SoundEventPath` 复用和平邀请音效。** 这是引擎的默认行为，mod 无法通过本类修改。
- **`AutoGenerated*` 成员不要碰。** 它们是序列化基础设施，签名可能随引擎版本变化。

## 真实示例

以下示例展示 mod 如何遍历地图通知列表，筛选出战参邀请并记录日志：

```csharp
using TaleWorlds.CampaignSystem;
using TaleWorlds.CampaignSystem.MapNotificationTypes;

public sealed class CallToWarOfferLogger : CampaignBehaviorBase
{
    public override void RegisterEvents()
    {
        CampaignEvents.TickMapEvent.AddNonSerializedListener(this, OnTick);
    }

    private void OnTick()
    {
        foreach (var notification in Campaign.Current.NotificationSet)
        {
            if (notification is AcceptCallToWarOfferMapNotification offer && offer.IsValid())
            {
                // 记录邀请信息，或触发自定义 UI
                InformationManager.ShowInquiry(new InquiryData(
                    "参战邀请",
                    $"{offer.OfferingKingdom.Name} 邀请你的王国向 {offer.KingdomToCallToWarAgainst.Name} 宣战。",
                    true, false, "确定", "", null, null));
            }
        }
    }

    public override void SyncData(IDataStore dataStore) { }
}
```

mod 也可以在通知过期后清理自己的追踪状态：

```csharp
foreach (var notification in Campaign.Current.NotificationSet)
{
    if (notification is AcceptCallToWarOfferMapNotification offer && !offer.IsValid())
    {
        // 通知已过期，可从自定义追踪列表中移除
    }
}
```
