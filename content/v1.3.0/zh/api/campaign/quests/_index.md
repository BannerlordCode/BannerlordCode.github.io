## 子系统概述

这里是 **campaign 目录** 的 **Quests** 子系统。同一命名空间下的类负责相近功能，可从中找到需要的类型后再进入类页查看方法。

任务日志与任务 UI。

## 类列表

| 类 | 用途 |
|------|---------|
| [`QuestBase`](../QuestBase/) | QuestBase 是一个抽象基类，位于 TaleWorlds.CampaignSystem，为具体子类提供可重写（override/virtual）的定制点。 |
| [`QuestCompleteDetails`](../QuestCompleteDetails/) | QuestCompleteDetails 是 TaleWorlds.CampaignSystem 下的公开类型。 |
| [`QuestManager`](../QuestManager/) | QuestManager 是一个管理器，位于 TaleWorlds.CampaignSystem，拥有子系统的生命周期、查找接口和跨对象协调职责。 |
| [`QuestStates`](../QuestStates/) | QuestStates 是 TaleWorlds.CampaignSystem 下的公开类型。 |
| [`QuestTaskBase`](../QuestTaskBase/) | QuestTaskBase 是一个抽象基类，位于 TaleWorlds.CampaignSystem，为具体子类提供可重写（override/virtual）的定制点。 |
