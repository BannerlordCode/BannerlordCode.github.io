# Campaign Behavior 长尾家族

## Mental Model

这些是官方 Campaign 行为实现的长尾索引。它们由 CampaignGameStarter 注册，订阅 CampaignEvents，在 SyncData 中保存自己的状态；读它们是为了理解调用顺序，不是为了复制内部单例。

## Dependencies

- [CampaignGameStarter](../CampaignGameStarter)、[CampaignEvents](../CampaignEvents)、[CampaignBehaviorBase](../CampaignBehaviorBase) 定义注册与生命周期。
- 持久变更回到 [Actions](../actions-index)，存档边界由 [IDataStore](../IDataStore) 控制。
