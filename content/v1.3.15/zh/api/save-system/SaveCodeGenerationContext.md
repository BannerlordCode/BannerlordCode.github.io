# SaveCodeGenerationContext

> **一句话职责：** 构建期工具，登记需要生成序列化代码的程序集，并把这些程序集里类型的存档读写代码生成为 `.cs` 文件写到磁盘。

**命名空间：** `TaleWorlds.SaveSystem.Definition`
**模块：** SaveSystem
**类型：** `class SaveCodeGenerationContext`
**源文件路径：** `bannerlord-1.3.15/TaleWorlds.SaveSystem/Definition/SaveCodeGenerationContext.cs`

## 概述
Bannerlord 的存档系统并不是纯运行时反射序列化，而是在编译期（或工具运行期）为每种 `[Saveable]` 类型生成专用的读写代码，`SaveCodeGenerationContext` 就是这套代码生成器的“工作区”。它持有 `DefinitionContext`，允许你 `AddAssembly` 登记目标程序集（含默认命名空间、输出目录与文件名），随后 `FillFiles` 遍历每个程序集、调用 `SaveCodeGenerationContextAssembly.Generate` 生成文本，并用 `File.WriteAllText` 落盘成自动生成的序列化器源码。

## 心智模型
把它想成“代码工厂的排产单”：你告诉工厂（上下文）这次要给哪些程序集（装配线）生成存档读写代码，以及成品 `.cs` 放哪、叫什么；工厂把每一条产线封装成 `SaveCodeGenerationContextAssembly`，统一开工、逐个写出文件。它是纯构建/工具期概念，和玩家运行时的 `SaveManager.Save` 不在同一条时间线上——运行时直接消费已生成的序列化器，根本不会碰这个类。modder 几乎不会用到它，除非你在做自定义代码生成管线。

## 何时用 / 何时不要用
仅当你在搭建或修改“存档代码生成”工具链（例如为新程序集产出 `AutoGenerated` 序列化器）时才用 `SaveCodeGenerationContext`。运行期模组保存请走 `SaveManager.Save(Game.Current, metaData, slotName, driver)`。把它误用在运行时不仅无意义，还会触发 `File.WriteAllText` 去写磁盘文件。

## 风险段
- 写盘副作用：`FillFiles()` 会真的调用 `File.WriteAllText` 把生成的 `.cs` 写到 `location + fileName`，路径须可写且正确，否则抛 IO 异常。
- 构建期专用：它依赖 `DefinitionContext` 已收集好类型定义，运行时调用属于误用。
- 程序集登记完整：漏掉某个含 `[Saveable]` 类型的程序集会生成不完整的序列化器，导致运行期保存时找不到定义。

## 成员说明
- 构造函数 `SaveCodeGenerationContext(DefinitionContext definitionContext)`：注入类型定义上下文，并初始化内部 `Dictionary<Assembly, SaveCodeGenerationContextAssembly>`。
- `void AddAssembly(Assembly assembly, string defaultNamespace, string location, string fileName)`：为某个程序集登记一条生成任务，封装成 `SaveCodeGenerationContextAssembly` 存入字典；`location`+`fileName` 决定输出路径。
- `internal SaveCodeGenerationContextAssembly FindAssemblyInformation(Assembly assembly)`：按程序集查回对应的生成上下文装配对象，供生成阶段取用。
- `internal void FillFiles()`：遍历所有登记的程序集，逐个 `Generate()` 并 `GenerateText()` 得到源码，最后用 `File.WriteAllText(..., Encoding.UTF8)` 写到磁盘。是生成流水线的执行入口。

## 示例
```csharp
ISaveDriver driver = new InMemDriver();
SaveOutput output = SaveManager.Save(Game.Current, metaData, "mySlot", driver);
LoadResult result = SaveManager.Load("mySlot", driver);
bool ok = result.Success;
```
