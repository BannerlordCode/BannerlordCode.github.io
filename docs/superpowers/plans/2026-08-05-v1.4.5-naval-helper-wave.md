## Goal

Replace the generated v1.4.5 `PortStateHelper` and `ShipHelper` references with source-backed handwritten English and Chinese pages. Keep the existing clean URLs and leave navigation artifacts untouched.

## Source contract

- `PortStateHelper` is a static entry facade. Every method creates a `PortState` through `GameStateManager.Current.CreateState` and immediately pushes it.
- `PortState` owns the selected `PortScreenModes` value, owners or supplied ship lists, and an optional `OnEndAction`; its `OnFinalize` invokes the callback.
- `OpenAsRestricted` accepts `restrictedReason`, but `PortStateHelper` does not pass it into `PortState`, so the argument has no effect in this source version.
- `ShipHelper` only reads presentation data or computes a transient raid-ship selection. It does not transfer ships, mutate party ownership, or start a naval mission.
- `GetOrderedNavalRaidShipsOfPlayerParty` filters `MobileParty.MainParty.Ships` to shallow-water ships, sorts by descending `MainDeckCrewCapacity`, and returns at most three.
