# Save system — 存档系统：类型注册与读写上下文

`TaleWorlds.SaveSystem` 及其 `Save`、`Load`、`Resolvers`、`Definition` 四个子命名空间。核心类型：`SaveManager`（静态门面）、`SaveContext`（写）、`LoadContext`（读）、`ISaveDriver`（后端）、`SaveableTypeDefiner`（类型注册）。

**先看 [存档系统](../../architecture/save-system) 再来。** 如果你的数据只在一个 `CampaignBehaviorBase` 里用，`SyncData` 就够了，根本不需要碰这个目录。

用了这个目录就意味着你要自己分配全局唯一的类型 ID —— 冲突会在读档时被静默解析成别的类型。
