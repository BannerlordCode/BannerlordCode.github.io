v1.3.0 → v1.3.15

v1.3.0 是 1.3 系列的早期基线，源码包仍然包含完整的 SandBox、StoryMode 及其 UI/View 层。v1.3.15 则把引擎拆成更多小而专的程序集。

从源码包中淡出或合并的模块

  • SandBox、SandBox.GauntletUI、SandBox.View、SandBox.ViewModelCollection
  • StoryMode、StoryMode.GauntletUI、StoryMode.View、StoryMode.ViewModelCollection
  • TaleWorlds.GauntletUI.TooltipExtensions
  • TaleWorlds.MountAndBlade.GauntletUI
  • TaleWorlds.MountAndBlade.View

这些玩法与视图层被合并进主 TaleWorlds.* 程序集，或随游戏本体分发而不再单独提供源码。

v1.3.15 新增的重点模块

  • 存档系统: TaleWorlds.SaveSystem 独立为顶层程序集；新增 TaleWorlds.MountAndBlade.SaveSystem.CodeGenerator。
  • 平台服务: TaleWorlds.PlatformService 及 Steam/Epic/GOG 实现；新增 TaleWorlds.PlayerServices。
  • 网络与联机: TaleWorlds.Network、TaleWorlds.Diamond 及其 AccessProvider、TaleWorlds.MountAndBlade.Diamond、TaleWorlds.ServiceDiscovery.Client。
  • 对象与屏幕基础设施: TaleWorlds.ObjectSystem、TaleWorlds.ScreenSystem、TaleWorlds.NavigationSystem、TaleWorlds.ModuleManager。
  • 引擎辅助: TaleWorlds.DotNet 与 .AutoGenerated、TaleWorlds.Engine.AutoGenerated、TaleWorlds.MountAndBlade.AutoGenerated、TaleWorlds.MountAndBlade.Helpers。
  • 启动器与创意工坊: TaleWorlds.MountAndBlade.Launcher 及 .Library/.Steam；TaleWorlds.MountAndBlade.SteamWorkshop。
  • 新的 UI 组件/集合: TaleWorlds.MountAndBlade.GauntletUI.Widgets、TaleWorlds.MountAndBlade.ViewModelCollection、TaleWorlds.TwoDimension 与 .Standalone。

对 mod 的影响

  1. 引用更新：如果使用存档类型，需要添加 TaleWorlds.SaveSystem.dll 引用。
  2. 玩法源码迁移：旧的 SandBox/StoryMode 命名空间路径现在多在 TaleWorlds.CampaignSystem 或 TaleWorlds.MountAndBlade 下。
  3. 生命周期不变：MBSubModuleBase 钩子保持兼容。

v1.3.15 → v1.4.5

新增或拆分的模块

  • TaleWorlds.CampaignSystem.FastMode — 战役加速/批处理
  • TaleWorlds.CampaignSystem.ViewModelCollection.BirthAndDeath — 生死系统 VM
  • TaleWorlds.MountAndBlade.CustomBattle — 自定义战斗
  • TaleWorlds.MountAndBlade.DedicatedCustomServer.ClientHelper
  • TaleWorlds.MountAndBlade.GauntletUI — M&B Gauntlet 独立模块
  • TaleWorlds.MountAndBlade.GauntletUI.AutoGenerated.0 / .1
  • TaleWorlds.MountAndBlade.Multiplayer 及其 GauntletUI/View/ViewModelCollection
  • TaleWorlds.MountAndBlade.Platform.PC
  • TaleWorlds.MountAndBlade.View
  • Modules.SandBox / Modules.StoryMode 玩法源码重新可见

移除的模块

  • TaleWorlds.MountAndBlade.GauntletUI.CodeGenerator
  • TaleWorlds.MountAndBlade.Launcher（保留 .Library/.Steam）
  • TaleWorlds.MountAndBlade.SaveSystem.CodeGenerator
  • TaleWorlds.MountAndBlade.SteamWorkshop

迁移检查清单

v1.3.0 → v1.3.15

  • 添加 TaleWorlds.SaveSystem 程序集引用。
  • 将旧的 MBSaveLoad 调用迁移到 SaveManager。
  • 检查 TaleWorlds.ObjectSystem、TaleWorlds.ScreenSystem、TaleWorlds.ModuleManager 等新模块引用。
  • 更新旧的 SandBox/StoryMode 命名空间路径到 TaleWorlds.CampaignSystem 或 TaleWorlds.MountAndBlade。

v1.3.15 → v1.4.5

  • 核对多人/Gauntlet/View 程序集路径，更新 .csproj 引用。
  • 更新 MobileParty 角色、Clan.CommanderLimit、Kingdom.HasCalledToWar 等破坏性变更。
  • 如需玩法内部实现，参考 Modules.SandBox/Modules.StoryMode 源码。
  • 保持 [SaveableField] ID 唯一，避免新增字段冲突。

迁移建议

  • 新 mod：推荐以 v1.3.15 为主文档版本，源码完整、API 稳定。
  • 面向 v1.4.5：重点处理多人/UI 模块拆分和上述破坏性类变更。
  • 存档兼容：不同版本的 .sav 一般不通用；跨版本需在 mod 描述中注明。
