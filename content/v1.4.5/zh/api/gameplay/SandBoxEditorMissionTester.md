# SandBoxEditorMissionTester

**Namespace:** `SandBox`
**Module:** SandBox
**Type:** `internal class SandBoxEditorMissionTester : IEditorMissionTester`
**Base:** `IEditorMissionTester`
**File:** `Bannerlord.Source/Modules.SandBox/SandBox/Sandbox/SandBoxEditorMissionTester.cs`

## 概述

`SandBoxEditorMissionTester` 是 17 行、2 个方法的无状态适配器。它实现 [IEditorMissionTester](../../mission-ext/IEditorMissionTester/) 的两个方法，每个方法只做一件事：造一个 [EditorSceneMissionManager](../../campaign-ext/EditorSceneMissionManager/)，强转成 `MBGameManager`，交给 `MBGameManager.StartNewGame`。

它由 `SandBoxSubModule.cs:25` 在模块加载时注册：

```csharp
Module.CurrentModule.SetEditorMissionTester((IEditorMissionTester)(object)new SandBoxEditorMissionTester());
```

调用侧在 `Module.cs`：`:1585` 的 `SetEditorMissionTester` 只是存引用，`:1591` 与 `:1600` 两个 `internal` 方法（带 `[MBCallback(null, false)]`，`:1590` 与 `:1599`）转发给存储的实例，而这两个 `internal` 方法的真正触发者来自 native 侧——`bin/TaleWorlds.MountAndBlade.AutoGenerated/ManagedCallbacks/CoreCallbacksGenerated.cs:1163` 与 `:1173` 的两个 `Module_StartMissionForEditor` 回调。

## 心智模型

把它当成**「编辑器入口的接线盒」**。三条推论：

第一，**它的两个方法都是显式接口实现**（`SandBoxEditorMissionTester.cs:7` 与 `:12`，方法名前带 `IEditorMissionTester.`）。**后果是：拿着 `SandBoxEditorMissionTester` 类型的变量调 `StartMissionForEditor` 编译不过**——必须先转成接口。这不是风格问题，是**唯一能防止外部绕过 `Module` 直接启动任务的地方**。

第二,**它不持有任何状态。** 全类两个字段都没有（`:5-16` 只有方法体）。**所以注册几个实例行为完全一样**，`Module.SetEditorMissionTester` 覆盖旧实例也不会丢状态——没有状态可丢。

第三,**`forReplay` 是两条路径唯一的实质差异。** `:10` 与 `:15` 都构造 `EditorSceneMissionManager`，前者 `forReplay: false` 且后面三个参数是空串/false/0f/0f，后者 `forReplay: true` 并把 `fileName`、`record`、`startTime`、`endTime` 一路透传。**其余七个参数完全一致。**

边界：**`internal` 类**，编译期不可引用；**但它实现的接口是 `public`**，所以从 `Module` 那一侧（`IEditorMissionTester` 引用）可以正常触达。

## 如何使用

**怎么拿到它**：正常路径是模块加载时自动注册（`SandBoxSubModule.cs:25`），之后从 `Module` 取。但 `Module._editorMissionTester` 是 `private`（`Module.cs:62`），`SetEditorMissionTester` 是公开的而**没有公开 getter**——**所以 mod 想读回当前是哪个实现，只能自己保存一份引用。**

读档回放路径的调用形状（对应 `EditorSceneMissionManager.cs:112` 转调 `StartMissionForEditorAux`）：

```csharp
using TaleWorlds.MountAndBlade;

// 与官方转发 Module.cs:1600 完全同形：7 个参数，forReplay: true
Module.CurrentModule.StartMissionForEditorAux(
    "SandBox.Campaign_Map",        // missionName
    "Map",                          // sceneName
    "Campaign_Map_Levels",          // levels
    forReplay: true,
    replayFileName: "my_replay.rec",
    isRecord: true,
    startTime: 0f,
    endTime: 30f);
```

自己注册一个实现——**这正是 `SetEditorMissionTester` 存在的意义**：

```csharp
using TaleWorlds.MountAndBlade;

public class MyEditorMissionTester : IEditorMissionTester
{
    void IEditorMissionTester.StartMissionForEditor(string missionName, string sceneName, string levels)
    {
        Debug.Print("intercepted editor start: " + missionName + " / " + sceneName, 0);
    }

    void IEditorMissionTester.StartMissionForReplayEditor(string missionName, string sceneName, string levels,
        string fileName, bool record, float startTime, float endTime)
    {
        Debug.Print("intercepted replay: " + fileName + " [" + startTime + "s .. " + endTime + "s]", 0);
    }
}

// 覆盖官方注册（SandBoxSubModule.cs:25）
Module.CurrentModule.SetEditorMissionTester(new MyEditorMissionTester());
Debug.Print("editor tester replaced", 0);
```

**用它最容易踩的一条**：**在编辑器里改坏了地图存不下，是因为 `StartMissionForReplayEditor` 的 `fileName` 是整条链上唯一一个决定「写到哪里」的参数。** `SandBoxSubModule.cs:25` 注册的是官方实现，编辑器工具发出的回放请求全部落到它那里。**覆盖它之后，编辑器保存功能会静默失效**——因为你的实现根本不 new `EditorSceneMissionManager`。

## 风险与边界

- **`internal` 类，编译期不可引用。** `new SandBoxEditorMissionTester()` 在 mod 代码里写不出来；只能实现接口再 `SetEditorMissionTester` 覆盖。
- **两个方法都是显式接口实现。** 拿具体类型直接调会编译失败。
- **注册发生在模块加载时。** `SandBoxSubModule.cs:25`。**mod 在 `OnSubModuleLoad` 之后的任意时刻注册都能生效**（`SetEditorMissionTester` 只赋值），但**没有公开 getter 让你确认是否被别的 mod 覆盖过**——只能用反射。
- **覆盖会丢掉编辑器保存能力。** 本类的两个方法都会 `StartNewGame`；你的实现不 new `EditorSceneMissionManager` 就没有任务在跑。**编辑器保存依赖回放路径。**
- **类无状态，但 `EditorSceneMissionManager` 有状态。** `EditorSceneMissionManager.cs:112` 会转调 `StartMissionForEditorAux`，**所以每次 `StartNewGame` 都是一次完整的场景重启**，不是「切场景」。
- **`StartMissionForEditor` 的 `fileName` 写死为空串。** 若编辑器某条路径误走了非回放分支，录制文件名为空——**没有校验会拦住它。**
