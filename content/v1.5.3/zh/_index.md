# Bannerlord v1.5.3 / 骑砍2 v1.5.3

## 心智模型

v1.5.3 是一个**源码完整**的版本：和 v1.3.0、v1.4.5 不同，这棵树把每个 `TaleWorlds.*` 程序集都以真实源码形式给出
（68 个 `TaleWorlds.*` 模块 + `SandBox` / `StoryMode`，共 11 487 个 `.cs`）。这就是为什么本版本能给出完整 API 目录，
而旧版本不能 —— 没有需要猜的东西。

把 SDK 想成一摞**只会向下依赖**的程序集：

```
   UI        GauntletUI · ScreenSystem · ViewModelCollection
   Mission   MountAndBlade · CustomBattle · Multiplayer
   Campaign  CampaignSystem · ObjectSystem · ActivitySystem
   Foundation Core · Library · DotNet · Localization · InputSystem
   Native    TaleWorlds.Native.dll（P/Invoke，不在本树范围内）
```

绝大多数 mod 只碰最上面三层：**Campaign**（世界规则）、**Mission**（单场战斗）、**UI**（界面）。
完整地图见 [SDK 分层概览](./architecture/sdk-overview)，程序集逐个查表见 [模块地图](./architecture/module-map)。

> **源码来源（provenance）**
> `bannerlord-1.5.3/` 是 **ILSpy 反编译产物** —— 11 487 个文件里有 11 398 个带 `// Token: 0x…` 标记。
> 签名可信，但排版是反编译器的，不是原作者的。这一点在做跨版本 diff 时很关键：
> 先读 [从 1.4.5 迁移](./architecture/migration-from-1.4.5)，再决定哪些差异能信。

## 怎么用这一版

1. **先建大局观。** [SDK 分层概览](./architecture/sdk-overview) 给分层模型与阅读顺序；
   [模块地图](./architecture/module-map) 给程序集对照表。
2. **按层进入。** 找到上表里对应你要做的那一层，点进那个目录。
3. **勤于回头。** 每个目录索引都链回 [API 参考](./api/) 和本页。
4. **要升级？** 先读 [从 1.4.5 迁移](./architecture/migration-from-1.4.5) —— 它是源码实测的，
   并且标明了哪些结论可以直接信。

## 使用示例

```csharp
// 1.5.3 的模块入口。具体实现类在 SandBox 模块里，基类在
// bannerlord-1.5.3/TaleWorlds.MountAndBlade/MBSubModuleBase.cs
public class MySubModule : MBSubModuleBase
{
    public override void OnGameStart(Game game, IModularState modularState)
    {
        base.OnGameStart(game, modularState);

        // Campaign 是世界状态根，所有世界事实都在这里读写。
        //   bannerlord-1.5.3/TaleWorlds.CampaignSystem/Campaign.cs
        if (Campaign.Current != null)
        {
            Clan clan = Clan.PlayerClan;
            // bannerlord-1.5.3/TaleWorlds.CampaignSystem/Clan.cs
        }
    }
}
```
