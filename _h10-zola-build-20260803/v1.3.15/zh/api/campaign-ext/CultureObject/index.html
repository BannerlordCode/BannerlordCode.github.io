CultureObject

CultureObject

Namespace: TaleWorlds.CampaignSystem
Module: TaleWorlds.CampaignSystem
Type: public sealed class CultureObject : BasicCultureObject
Base: BasicCultureObject（位于 TaleWorlds.Core）
File: TaleWorlds.CampaignSystem/CultureObject.cs

概述

CultureObject 是战役世界里一个文化阵营的全部静态数据：它定义了这个文化出什么兵（BasicTroop / 民兵）、城镇里刷什么平民与工匠 NPC、用什么家族名和英雄名、旗帜主色是什么、建国时默认走哪些政策、以及领主/商队/巡逻队用哪套 PartyTemplateObject。Clan、Kingdom、Settlement、CharacterObject 都只保存一个对 CultureObject 的引用，运行时绝大多数“文化相关”表现（兵种、配色、命名）都是去读这个共享对象得到的。它是从 SPCultures XML 反序列化出来的、全局唯一的只读配置，几乎所有涉及“按阵营区分外观与单位”的 mod 都要和它打交道。

心智模型

把 CultureObject 当作**“一个阵营的户口本 + 兵工厂配置表”**，而不是一个会自己活动的对象：

  • 它本身不参与 tick、不持有逻辑；它只是被别的系统读取的数据容器。
  • 每个文化在战役初始化时由 MBObjectManager 从 SPCultures XML 一次性反序列化，之后作为单例被全局共享。你通常不应该 new 一个 CultureObject，而是通过 Clan.Culture、Kingdom.Culture、Settlement.Culture、CharacterObject.Culture 或 MBObjectManager 去拿到已存在的实例。
  • 它处在数据层 / 配置层（属于 TaleWorlds.CampaignSystem 的对象系统，继承自 TaleWorlds.Core 的 BasicCultureObject），不是行为层（CampaignBehavior）、也不是模型层（Model）。想“改某个阵营的行为”，应当改引用它的 Clan/Kingdom 或对应的 Behavior/Model，而不是直接改写这份共享配置。
  • 何时用：需要读取某阵营的兵种、配色、命名表、装备、部队模板时；需要根据文化做招募、命名、旗帜、叛军生成等逻辑时。
  • 何时不要用：想改变一个家族/王国的实际归属阵营时，应改 Clan.Culture（可写）或走建王国流程，而不是去复制/新建 CultureObject；想改变“某次战斗里某单位的表现”，应改 CharacterObject 或装备，而不是改文化的全局模板（会影响该文化所有单位）。
  • 依赖：被 MBObjectManager 加载与存档引用收集；被 NameGenerator 读取命名表；被各类 PartyTemplateObject / CharacterObject / ItemObject / FeatObject / PolicyObject 反向引用。
  • 失败模式：大量系统直接解引用 culture.DefaultPartyTemplate、culture.BasicTroop、culture.MaleNameList 等；一个缺失这些引用的文化会在相关系统运行（部队生成、锦标赛、命名）时抛 NullReferenceException。文化中绝大多数字段是 private set，只有 MilitiaBonus / ProsperityBonus 可写。

依赖图

上游（谁创建 / 拥有 / 存档）

  • MBObjectManager — 战役初始化时从 SPCultures XML 反序列化全部 CultureObject，并在每次存档时通过 AutoGeneratedInstanceCollectObjects 收集其引用的 CharacterObject / PartyTemplateObject / ItemObject 等。这是文化对象的存档点。
  • BasicCultureObject — 基类，提供 Name、IsMainCulture、IsBandit、Color / Color2、ClothAlternativeColor*、BackgroundColor* / ForegroundColor*、Banner、EncounterBackgroundMesh 等身份与外观字段。
  • TextObject — Name、MaleNameList、FemaleNameList、ClanNameList、EncyclopediaText 均为 TextObject。
  • MBReadOnlyList / Banner — 多数集合与旗帜类型来自这两个底层类型。

下游（谁消费这份配置）

  • Clan — Clan.Culture（{ get; set; }）决定家族兵种、家族名、旗帜色；它是可写的，可在运行时切换家族阵营。
  • Kingdom — Kingdom.Culture（{ get; private set; }）决定王国兵种与旗帜，外部只读。
  • Settlement — Settlement.Culture（public CultureObject Culture;）决定据点里的平民/工匠 NPC 模板与民兵兵种。
  • CharacterObject — CharacterObject.Culture（public new CultureObject Culture）决定人物默认装备 rosters 与阵营。
  • NameGenerator — 生成英雄名/家族名时读取 MaleNameList / FemaleNameList / ClanNameList。
  • FeatObject / PolicyObject / PartyTemplateObject / ItemObject — 文化的特性、默认政策、各类部队模板与奖励物品。

行为 / 模型（真实调用点）

  • CampaignBehaviorBase — 多数战役 Behavior 通过 MBObjectManager.Instance.GetObjectTypeList<CultureObject>() 遍历所有文化。
  • RebellionsCampaignBehavior — 起义/叛军逻辑遍历文化以选取 RebelliousHeroTemplates。
  • GovernorCampaignBehavior 与 KingdomCreationModel — 玩家建王国时通过 KingdomCreationModel.GetAvailablePlayerKingdomCultures() 暴露可选文化列表。

存档点

文化对象由 MBObjectManager 持有；Clan / Kingdom / Settlement / CharacterObject 以 id 字符串形式保存对文化的引用，读档时由 MBObjectManager 解析回同一实例。修改或删除某个文化的 id 会导致读档时引用无法解析（得到 null），进而在下游解引用处崩溃——这是主要的坏档风险。

风险段

  • 改 id / 删除文化 = 坏档：Clan.Culture、Kingdom.Culture、Settlement.Culture、CharacterObject.Culture 都以字符串 id 存进存档。若你新增的文化 id 与已存档引用不匹配，或改了原版文化的 id，读档时 MBObjectManager 解析为 null，随后领主部队生成、命名、旗帜等解引用会抛异常。新增文化请在模组 XML 里使用稳定、唯一的 id，并保持向后兼容。
  • 别直接写只读模板字段：BasicTroop、DefaultPartyTemplate、Color、MaleNameList 等都是 private set，从外部赋值会被编译器拒绝；强行走反序列化或反射改写会影响该文化所有家族/据点/单位，且不会被存档自然恢复。需要“定制单位”应改具体的 CharacterObject 或 PartyTemplateObject。
  • 缺模板的文化会运行时崩溃：很多系统直接解引用 culture.DefaultPartyTemplate / culture.BasicTroop / culture.MilitiaPartyTemplate。自建文化务必填齐这些引用，否则领主队、民兵、锦标赛生成时会 NullReferenceException。
  • MilitiaBonus / ProsperityBonus 可写但有全局副作用：这是 CultureObject 上仅有的两个可写属性。在战役中改它们会立刻影响该文化所有据点的民兵/繁荣加成；它们不属于常规的“平衡修改”入口，改之前确认这正是你想要的范围。
  • 命名表可能为空：NameGenerator 内部已用 IsEmpty() 保护，但若你直接读 MaleNameList / FemaleNameList 并假设非空，对某些特殊文化（如 neutral_culture）可能拿不到名字。

成员说明

身份与外观（继承自 BasicCultureObject）

  • Name（TextObject，只读）— 文化的显示名（如“斯特吉亚”）。ToString() 与 GetName() 都直接返回它。
  • IsMainCulture（bool，只读）— 是否为可游玩的主文化；KingdomCreationModel.GetAvailablePlayerKingdomCultures() 通常只返回 IsMainCulture == true 的文化。
  • IsBandit（bool，只读）— 是否为强盗文化（如山贼、海寇）。
  • CanHaveSettlement（bool，只读）— 该文化能否拥有定居点。
  • Color / Color2（uint，只读）— 阵营主色与副色（ARGB 十六进制，对应“势力颜色”）。Clan / Kingdom 的旗帜与地图色块读这里。
  • ClothAlternativeColor / ClothAlternativeColor2（uint，只读）— 布料备用色。
  • BackgroundColor1 / BackgroundColor2 / ForegroundColor1 / ForegroundColor2（uint，只读）— 旗帜背景/前景配色。
  • Banner（Banner，只读）— 该文化的默认阵营旗帜。
  • EncounterBackgroundMesh（string，可读写）— 野外遭遇战背景网格名。

基础兵种与民兵（CharacterObject）

  • BasicTroop（CharacterObject，只读）— 该文化的一级新兵模板，是招募链的起点。Clan / 城镇招募都从这里开始升级。
  • EliteBasicTroop（CharacterObject，只读）— 精英版基础兵种。
  • MeleeMilitiaTroop / RangedMilitiaTroop / MeleeEliteMilitiaTroop / RangedEliteMilitiaTroop（CharacterObject，只读）— 据点民兵与精英民兵模板，由 MilitiaPartyTemplate 与村庄民兵生成使用。
  • 强盗模板 BanditChief / BanditRaider / BanditBandit / BanditBoss（CharacterObject，只读）— 该强盗文化各档位的单位；其中 BanditBossPartyTemplate 对应 BanditBoss 的部队模板。

读取示例（见下方“真实示例”）里用 culture.BasicTroop 即可拿到招募起点，不要自己凭 id 猜测兵种。

城镇 / 平民 / 工匠 NPC 模板（CharacterObject）

以下字段是一组在属于该文化的据点中刷新的平民与功能 NPC 模板，通常供 Settlement / Town / Village 与工坊、任务系统使用：

TournamentMaster、Villager、CaravanMaster、CaravanGuard、PrisonGuard、Guard、Blacksmith、Weaponsmith、Townswoman（及其 Infant / Child / Teenager 变体）、Townsman（含 Infant / Child / Teenager）、VillageWoman、Villager（含 MaleChild / MaleTeenager / FemaleChild / FemaleTeenager）、RansomBroker、GangleaderBodyguard、MerchantNotary / ArtisanNotary / PreacherNotary / RuralNotableNotary、ShopWorker、Tavernkeeper、TavernGamehost、Musician、TavernWench、Armorer、HorseMerchant、Barber、Merchant、Beggar / FemaleBeggar、FemaleDancer、Shipwright、MilitiaVeteranArcher、GearDummy。

这些字段都是只读的 CharacterObject；它们决定了“某个文化的城镇长什么样”。自定义据点生态时应从这里取模板，而不是另建一套。

名称 / 领主 / 家族模板集合

  • MaleNameList / FemaleNameList（MBReadOnlyList<TextObject>，只读）— 英雄名库；NameGenerator.Current.GetNameListForCulture(culture, isFemale) 与英雄命名都读这里。
  • ClanNameList（MBReadOnlyList<TextObject>，只读）— 家族名库；NameGenerator.Current.GenerateClanName(culture, settlement) 读这里。
  • NotableTemplates / LordTemplates / RebelliousHeroTemplates（MBReadOnlyList<CharacterObject>，只读）— 名望人士、领主、叛军英雄的模板集合；叛军/家族生成从这些里挑。
  • BasicMercenaryTroops（MBReadOnlyList<CharacterObject>，只读）— 该文化可招募的雇佣兵基础单位。
  • TournamentTeamTemplatesForOneParticipant / ForTwoParticipant / ForFourParticipant（MBReadOnlyList<CharacterObject>，只读）— 锦标赛队伍模板（按参赛人数分组）。

装备 Roster（MBEquipmentRoster）

  • DefaultBattleEquipmentRoster — 该文化单位的默认战斗装备。
  • DefaultCivilianEquipmentRoster — 平民默认装备。
  • DefaultStealthEquipmentRoster — 潜行装备（被 CharacterObject 的装备选取逻辑读取）。
  • DuelPresetEquipmentRoster — 决斗预设装备。
  • MarriageBrideEquipmentRoster — 婚礼新娘装备。

部队模板（PartyTemplateObject）

  • DefaultPartyTemplate（PartyTemplateObject，只读）— 最关键的模板：领主队 / 家族部队生成时解引用它来决定编成。自建或替换文化时务必保证非空。
  • VillagerPartyTemplate / FishingPartyTemplate / MilitiaPartyTemplate / RebelsPartyTemplate — 村民队、渔船队、民兵队、叛军队的模板。
  • BanditBossPartyTemplate / VassalRewardTroopsPartyTemplate — 强盗首领队、封臣奖励部队模板。
  • SettlementPatrolPartyTemplateWeak / Moderate / Strong / Naval — 据点巡逻队的弱/中/强/海军四档模板。
  • CaravanPartyTemplates / EliteCaravanPartyTemplates（MBReadOnlyList<PartyTemplateObject>）— 普通与精英商队模板集合。

特性 / 政策 / 数值 / 杂项

  • Traits（CultureTrait[]，只读）— 该文化的文化特性数组；用 HasTrait 判定。
  • CultureFeats（MBReadOnlyList<FeatObject>，只读）— 文化特性（feat）集合；用 HasFeat / GetCulturalFeats 读取。
  • DefaultPolicyList（MBReadOnlyList<PolicyObject>，只读）— 建国时默认采用的政策集合。
  • PossibleClanBannerIconsIDs（MBReadOnlyList<int>，只读）— 该文化家族可使用的旗帜图标 id 列表。
  • MilitiaBonus / ProsperityBonus（int，可读写）— 民兵/繁荣加成；这是整类里仅有的两个可写属性。
  • NavalFactor（float，只读）— 海军权重，影响海军相关逻辑。
  • BoardGame（BoardGameType 枚举，只读）— 该文化的棋类游戏类型（None / Seega / Puluc / Konane / MuTorere / Tablut / BaghChal）。
  • StartingPoint（CampaignVec2，只读）— 战役起始点坐标。
  • EncyclopediaText（TextObject，只读）— 百科条目描述文本。
  • DefaultCharacterCreationBodyProperty（MBBodyProperty，只读）— 角色创建时的默认体型。
  • AvailableShipHulls（MBReadOnlyList<ShipHull>，只读）— 可用船体集合（海军）。
  • VassalRewardItems / BannerBearerReplacementWeapons（MBReadOnlyList<ItemObject>，只读）— 封臣奖励物品、旗手替换武器集合。

方法

public bool HasTrait(CultureTrait trait)

判断该文化是否拥有某个 CultureTrait。

CultureObject culture = Clan.PlayerClan.Culture;
if (culture.Traits != null && culture.Traits.Length > 0)
{
    CultureTrait first = culture.Traits[0];
    if (culture.HasTrait(first)) // 判断该文化是否具备某个 CultureTrait
    {
        // 针对该特性做阵营加成或事件分支
    }
}

public bool HasFeat(FeatObject feat)

判断该文化是否包含某个 FeatObject（特性，例如“森林适应”“沙漠适应”）。

CultureObject culture = Settlement.CurrentSettlement.Culture;
foreach (FeatObject feat in culture.CultureFeats)
{
    if (culture.HasFeat(feat) && feat.IsPositive)
    {
        // 读取 feat 的战斗/地图修正（EffectBonus / IncrementType）
    }
}

public IEnumerable<FeatObject> GetCulturalFeats(Func<FeatObject, bool> predicate = null)

返回文化特性，可传入过滤委托。空参则返回全部。

var positiveFeats = Clan.PlayerClan.Culture.GetCulturalFeats(f => f.IsPositive);

public override TextObject GetName()

返回文化的显示名（base.Name）。ToString() 同样返回 Name 的字符串形式。

TextObject name = Clan.PlayerClan.Culture.GetName();
InformationManager.DisplayMessage(new InformationMessage(name.ToString()));

public override void Deserialize(MBObjectManager objectManager, XmlNode node)

内部方法：从 SPCultures XML 节点反序列化全部字段与子集合。不是给 mod 调用的 API，由对象系统在加载阶段调用；手动调用会破坏已初始化的全局状态。

真实示例

示例 1：拿到玩家家族的文化并读取兵种与配色

// 真实获取路径：Clan.Culture（可写属性）
CultureObject playerCulture = Clan.PlayerClan.Culture;
if (playerCulture != null)
{
    CharacterObject recruit = playerCulture.BasicTroop;          // 一级新兵模板
    uint primaryColor = playerCulture.Color;                     // 阵营主色（ARGB）
    bool isBandit = playerCulture.IsBandit;                      // 是否强盗文化
    InformationManager.DisplayMessage(new InformationMessage(
        $"{playerCulture.Name}：基础兵种 {recruit.Name}，主色 #{primaryColor:X8}"));
}

示例 2：遍历所有文化，挑出主文化并用其命名表生成家族名

// 真实获取路径：MBObjectManager.Instance.GetObjectTypeList<CultureObject>()
foreach (CultureObject culture in MBObjectManager.Instance.GetObjectTypeList<CultureObject>())
{
    if (!culture.IsMainCulture)
    {
        continue; // 只处理可游玩的主文化
    }

    // NameGenerator 读取该文化的 ClanNameList / MaleNameList / FemaleNameList
    TextObject clanName = NameGenerator.Current.GenerateClanName(culture, null);
    CharacterObject elite = culture.EliteBasicTroop;

    // 例如：为自定义招募逻辑收集每个文化的精英兵种
    if (elite != null)
    {
        // 加入你的招募池 ...
    }
}

示例 3：按 id / 从其他对象取得文化（常用获取路径汇总）

// 1) 按字符串 id 直接取（原版文化 id 如 "empire"、"aserai"、"vlandia"、"sturgia"、"khuzait"、"battania"、"nord"、"neutral_culture"）
CultureObject empire = MBObjectManager.Instance.GetObject<CultureObject>("empire");

// 2) 从据点取
CultureObject settlementCulture = Settlement.CurrentSettlement.Culture;

// 3) 从王国取（Kingdom.Culture 只读）
CultureObject kingdomCulture = Clan.PlayerClan.Kingdom?.Culture;

// 4) 从英雄/人物取（CharacterObject.Culture 是 public new CultureObject Culture）
CultureObject heroCulture = Hero.MainHero.CharacterObject.Culture;

跨版本提示

  • v1.3.0：本类已存在，但缺少 SettlementPatrolPartyTemplateNaval、NotableTemplates、RebelliousHeroTemplates、LordTemplates、TournamentTeamTemplatesForOneParticipant / ForTwoParticipant / ForFourParticipant、BasicMercenaryTroops 这些成员；这些是在 v1.3.15 加入的。
  • v1.3.15（本页）：命名空间仍为 TaleWorlds.CampaignSystem，字段集与 1.4.5 基本一致。语义以 1.4.5 权威源为准。
  • v1.4.5：与 1.3.15 对本类无实质差异；Clan.Culture 仍为可写、Kingdom.Culture 仍为只读。
