# v1.4.5 Party Lifecycle Action Wave Implementation Plan

> **For agentic workers:** Use a single source-reading author for the eight page rewrites, then an independent reviewer. Do not use body generators or modify pages outside this plan.

**Goal:** Replace the v1.4.5 `DisbandPartyAction`, `LeaveSettlementAction`, and `TransferPrisonerAction` stubs with source-backed bilingual pages that explain party lifecycle transitions without teaching unsafe field edits.
