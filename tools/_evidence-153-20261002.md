### 2.1 识别方法（两道独立判据）

**主判据 = 写作者溯源白名单。** 一页只有落在下列白名单内才算手写，白名单外**一律判生成**。溯源问的是「谁写的」，不是「长得像不像」。

**交叉验证 = 6 个模式信号并集**：
- `skeleton-self-description`：`自动生成的初始占位段落` / `自动生成类参考` / `Auto-generated stub for` / `Auto-generated initial placeholder` / `Auto-generated index of` / `Every leaf page is a stub`
- `policy-boilerplate`：`阅读时先通过属性了解状态` / `是 TaleWorlds.X 下的公开类型` / `null; // 替换` / `SomeValue` / `service = ...` / `从实际子系统 API`
- `generator-block`：`## 模块心智模型` / `<!-- BEGIN SECTION INDEX -->` / `<!-- BEGIN CARVE-OUT NOTE -->`

**一致性结果**：
- 13 663 个生成页**全部带至少一个信号**，检测盲区 **0**
- 37 个手写页中 4 页带 `generator-block` 信号 → **逐页核实为非污染**（见 §2.3）
