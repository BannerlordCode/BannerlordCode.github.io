Campaign

Campaign

Namespace: TaleWorlds.CampaignSystem Module: TaleWorlds.CampaignSystem Type: public class Campaign : GameType Base: GameType File: TaleWorlds.CampaignSystem/Campaign.cs

概述

Campaign 位于 TaleWorlds.CampaignSystem，它通过这组公开成员把对应子系统的状态、行为或流程入口暴露给 mod 开发者。阅读时先看属性代表“它持有什么状态”，再看方法代表“它允许你做什么”。

心智模型

先从命名空间 TaleWorlds.CampaignSystem 判断它属于哪层系统，再看公开方法：如果以 Get/Set 为主，它多半是状态对象；如果以 Create/Apply/Execute 为主，它更像服务或流程入口。
