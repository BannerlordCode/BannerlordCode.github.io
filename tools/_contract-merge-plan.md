## 1. 🔴 实测推翻了「膨胀 = 同一条判据被写了五次」这个诊断

boss 的判断是「今天的膨胀不是因为判据太多，是因为同一条判据被写了五次」。
**数据不支持「写了五次」** —— 它支持的是另一件事。

### 1.1 同一对规则，正文几乎不重合

| 节对 | 标题相似 | **正文 10-gram 重合** | 行数 | boss 归类 |
|---|---:|---:|---|---|
| §4h ↔ §6t | 59% | **0%** | 22 / 43 | 甲 |
| §4f ↔ §6s | 20% | **5%** | 27 / 29 | 未点名 |
| §4i ↔ §7p | 19% | **0%** | 19 / 18 | 丙 |

**三对的正文重合都是 0%–5%。** 也就是说：
```
它们不是同一段话被抄了两遍，
而是【同一条规则被两次独立地、用不同措辞各写了一遍】。
```

**⇒ 这改变了合并的做法**：甲类不是「删一份」，是**「两份措辞要有人裁决，保留一份」**。
按「删内容」去做，会丢掉两份里各自独有的实例 —— 而 §6t 有 43 行、§4h 只有 22 行，
它们各自携带的实例大概率不同。

### 1.2 「乙」的候选其实不是实例，是**平行的独立规则**

boss 把 §4c §4d §4k §4s §4t 归为「乙：总纲 + 实例，应指向 §4w」。实测：

| 节对 | 正文重合 | 实际关系 |
|---|---:|---|
| §4c ↔ §4w | 0% | §4c = 禁用工具时须附具体错数；§4w = 报 N 前须排两类重复 |
| §4d ↔ §4k | 0% | 都是「正则匹配到 0」，但一个管落笔、一个管派单 |
| §4s ↔ §4w | 0% | §4s = 两种引用形态分开统计；§4w = 同一文件重复计数 |
| §4t ↔ §4w | 0% | §4t = 哪些成员算「唯一」；§4w = 报 N 前排重复 |

**它们共享的是【主题】而不是【内容】。** 把它们降为「指向 §4w 的实例」会造出一条**它们并不从属的总纲**。

### 1.3 真正的病灶：不是重复，是**没有共享词汇表**

按主题聚类（同一主题命中多少节）：

| 主题 | 命中节数 |
|---|---:|
| 取证要求 | **33** |
| 尺的范围 / 边界 | **24** |
| 报数口径 / 未计入项 | **26** |
| 归属（谁写的） | 10 |

**33 节在讲「怎么取证」，26 节在讲「报数要带口径」，而它们几乎不互相引用。**
**⇒ 膨胀的机制是：每次事故都新开一节，用当时那个 worker 的措辞写，没有人回头把它归到已有的类目下。**

**⇒ 所以「合并同类」若按「找重复节」去做，最多删掉 5 节，59 → 54，收益极小。**
**⇒ 真正该做的是给这四个主题各立一个 10 行的**词汇表**（哪一格属于哪一类），
然后把 33 / 26 / 24 节各挂一个标签 —— 不改正文，只加归类。**

## 3. 我建议的动作（与 boss 的「先清单、后动文件」一致）

```
第一步  给「取证 / 报数口径 / 尺边界 / 归属」四个主题各写一个 10 行词汇表
第二步  给 59 节各加一行「主题：X · 本节在 X 类里的位置」
第三步  跑一次「同主题下措辞相近」的重扫，看还剩几对真重复
第四步  那时才决定删哪几节 —— 而那时删的会是【已经归好类的重复】，不是现在的散落重复
```

**第一步与第二步都不删任何内容，因此风险极低；而它们直接解决「33 节讲取证却互不引用」这个真正的病灶。**
