## 6. GATE RECOMMENDATION

Two distinct gate gaps produced this round's only rejection and my previous round's only rejection:

1. **Absence/negative-claim verification** (this round). For any page asserting "X has zero occurrences" / "no caller anywhere", re-run that exact grep against the *target version tree* at review time. Cheap, mechanical, and it would have caught `AgentSaveData` immediately.
2. **Return-type checking in call position** (last round). Flag assignment of a call whose declaration returns `void`. This is what caught `RotateCCW`.

**Both are false-positive-prone** if run without the framing check I applied by hand — so I recommend shipping them as *review prompts*, not auto-reject triggers. That distinction is the main practical finding from these two rounds: **a mechanical check reliably locates the suspect; only reading decides whether it is a defect.**
