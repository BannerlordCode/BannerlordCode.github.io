## 2. 修复设计（只加强，不削弱）

> 原则：放宽只发生在**捕获**（吃到路径），收紧发生在**无法判定**（fail closed）。不放宽任何阈值/白名单/已知失败清单/MODE/exit 语义。

| # | 位置 | 修前 | 修后 | 方向 |
| - | - | - | - | - |
| F1 | `REF_RE` | 捕获组不含 `/` | 允许路径段 `(?:[\w.-]+\/)*` | 加强（吃到路径） |
| F2 | `resolveSource()` | 路径分支死代码；`cand.length===0` 落回 ambiguous | 路径分支生效；0 候选 ⇒ `not-found`；唯一 ⇒ ok；多 ⇒ ambiguous | 加强 |
| F3 | `check()` | `ambiguous` ⇒ 静默 return（跳过 J3+J13） | `ambiguous` ⇒ 计数 + **fail closed**（报不确定 ⇒ 该页 FAIL） | 加强 |
| F4 | `subjectFile()` | 只取 basename | 携带页面声明的路径（裸 `:N` 归属吃到路径） | 加强 |

**安全性论证**：`resolveSource()` 先按 basename 查；**basename 唯一 ⇒ 行为与修前逐字节相同**（路径分支不可达）。路径信息只在 basename 重名时被消费。⇒ F1 不会改变任何「非重名引用」的判定。

**exit 语义不变**：fail closed 通过追加 `fail` 条目实现 ⇒ 页面 FAIL ⇒ 判分器 `exit 1`（既有语义）。未改 exit code 约定。
