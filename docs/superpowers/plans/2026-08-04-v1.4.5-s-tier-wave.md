# v1.4.5 S-Tier Handwritten Wave Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Each task is a bilingual handwritten documentation rewrite followed by an independent review.

**Goal:** Reduce the v1.4.5 R1/S-tier gap with four source-backed bilingual deep pages while preserving clean routes and the handbook's safety model.

**Architecture:** Rewrite the existing v1.4.5 leaf URLs in place.
