概述

Opengl32ARB 位于 TaleWorlds.TwoDimension.Standalone.Native.OpenGL，它通过这组公开成员把对应子系统的状态、行为或流程入口暴露给 mod 开发者。阅读时先看属性代表“它持有什么状态”，再看方法代表“它允许你做什么”。
