# Core, Library, and Engine platform long tail

## Mental Model

These identities belong to the managed platform layer. Core and Library provide value objects, serialization, and diagnostics; Engine provides managed scene, rendering, physics, and native-bridge wrappers. Mods should depend on these managed entry points, never treat `[EngineMethod]` names or native addresses as a stable ABI.

## Dependencies

- [Engine](../) and [Native Reference](../../../native/) define the managed/native boundary; CampaignSystem still owns persistent campaign state.

## Source provenance

Type identities and page paths come from `tools/data/type-inventory.json`. Engine native relationships are traced only through managed wrappers and `native-1.3.15-src` evidence pages; this page does not expand the native class sea.
