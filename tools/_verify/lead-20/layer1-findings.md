## 1. 结论（一句话）

**Layer 1 的 `2,746` 不是「2,746 处编造」，而是「2,746 处未在该页版本树的 `.cs` 文件里出现」。**
这两句话不等价，而检测器的构建方式决定了它**在结构上**无法区分它们。

⇒ 因此 Layer 1 记 **UNMEASURED**（不是「待做」，是「按设计不可判定」），该线关闭。
⇒ 该目标的**正式判据是 J13**（窄而精确：lead-18 已冻结的 30 页里抓出 12 条真缺陷，假阳性近零）。

## 2. 两条【结构性】结论（比任何抽样结果都强）

### 2.1 索引只扫 `.cs` ⇒ BCL 类型 / 配置键 / 占位记号**必然**被判为「不存在」
```
Layer 1 的索引由【只扫 `.cs` 文件的全 token 扫描】构建（treeids 索引），不是 live grep。
⇒ `InvalidCastException`、`Extensions__TaleWorlds_Core`、`OnXxx`、`XxxModel` 这类
   【按定义就不在游戏源码里】的 token，在结构上必然进入 flags。
⇒ 所以 2,746 里有【一整类】是构造性的假阳性，不需要抽样就能断言。
```

### 2.2 检测器**只查一棵树** ⇒ 无法区分「不存在」与「只在这里不存在」
```
页面在 v1.4.7，而标识符只存在于 v1.4.6/1.4.7/1.5.3 中的【另一棵】时，检测器报「不存在」。
★ 独立确认（lead-20 亲自复算，非采信报告）：
    `AddModule`（own=1.4.5）→ 1.4.5【0 文件】，但 1.4.6 / 1.4.7 / 1.5.3【各 2 文件】
    `AddDynamicEntityInfo`（own=1.3.0）→ 六棵树全 0（真不存在，属 (a) 候选）
    `AgentLookDirection`（own=1.3.0）→ 六棵树全 0（真不存在，属 (a) 候选）
⇒ 这是【设计级】局限，与 2.1 同权重：它不能靠扩大样本量消掉。
```

## 3. 七类分类（本线 brief 给 5 类，实测发现需扩到 7 类）

| # | 类别 | 是否假阳性 | 说明 |
|---|---|---|---|
| (a) | 真编造 | **否**（真缺陷） | 全树皆无、且页面确实在断言它存在 |
| (b) | BCL / .NET 类型 | 是 | `InvalidCastException` · `StackOverflowException` · `List` |
| (c) | 占位 / 模式记号 | 是 | `OnShipXxx` · `AddXxx` · `XxxModel` · `OnXxx` · `TOther` · `MyDefectionModel` |
| (d) | 配置键 / 路径 / 其它 | 是 | `Extensions__TaleWorlds_Core` · `DependantModules` |
| (e) | 否定句上下文 | 是 | 页面说「X 不存在」/「does not exist」 |
| **(f)** | **版本错位（VERSION-SKEW）** | 是 | ★ 本批新发现：标识符存在于**另一棵**版本树 |
| **(g)** | **子串片段（SUBSTRING FRAGMENT）** | 是 | ★ 本批新发现：被标 token 是真实名的片段 |

### (g) 为什么值得单列：它是**词边界规则的反向失效**
```
· `WriteObject` vs `WriteObjects`（复数）：【子串】抬高存在性 ⇒ 需要词边界
· `FemaleChild` / `GlobalFrame` / `CivilianEquipment` / `WithDoubleValue`：
  【词边界】拒绝了一个合法片段 ⇒ 这是同一个规则在【相反方向】上的失效
⇒ 两个方向现在都被实测到了。**任何「用词边界做存在性检查」的实现都该知道这两个方向都存在。**
```
**⇒ 而 (f) 与 (g) 都必须【分开计数】** —— 把它们并进一个「假阳性率」会丢掉成因，
而**成因才是这份文件的价值所在**。

## 7. 一条方法论（本线的处置顺序，值得记档）

```
★ **取消一个 worker 之前，先把它【已经产出的、已验证的部分】落盘** ——
  否则「取消」会连带丢弃已完成的测量，而它【不可回放】。
⇒ 本线实际顺序：① 确认证据 value-valid（规则 ① 值抽查）→ ② 才取消 worker → ③ 保留发现
⇒ 反例（本会话真实发生过）：worker-198 交付后【清理了临时站】，导致它的 A/B 读数
   「有旁证支持但无法直接复验」—— 清理发生在复核之前。
```
