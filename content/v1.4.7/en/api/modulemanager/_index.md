# Modulemanager — ModuleManager: module metadata

The 8 types of `TaleWorlds.ModuleManager`: `ModuleInfo`, `SubModuleInfo`, `ModuleCategory`, `ModuleType`, `SubModuleTags`, `DependedModule`, `IPlatformModuleExtension`, `Extensions`, `ModuleHelper`.

Use it to **read** the module list: is a module loaded, what depends on it, which version. To **add** a module, read [Core](../core/) and [Module System](../../architecture/module-system).

Note: **no version contains a type called `ModuleManager`** (verified by a full scan of 1.4.5 / 1.4.6 / 1.4.7 / 1.5.3), so there is no `ModuleManager.md` here.
