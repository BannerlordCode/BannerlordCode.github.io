开发者任务路线图 — 我想做 X 该读哪（v1.3.15）

开发者任务路线图

不按字母表找类。先在这里定位你要做的「任务」，顺着依赖链点进具体类页。每格都链到已手写页；未写完的家族（Actions / Models）链到模块桶并标注编写中。

任务 → 入口类

1. 注册 SubModule 并在战役里加 Behavior

依赖链：MBSubModuleBase（SubModule 入口，页面编写中 → 见 core 模块）→ CampaignGameStarter.AddBehavior<T> → 你的 CampaignBehaviorBase 子类。

  • CampaignGameStarter
  • CampaignBehaviorBase
  • CampaignEventReceiver（订阅战役事件）
  • 风险：见 崩溃边界 · SubModule 加载阶段 与 Campaign 事件时机

2. 安全地改世界状态（给钱 / 杀人 / 改王国）

原则：永远走 *Action.Apply，不要直接改字段（直接改会跳过事件级联、坏档、AI 失同步）。

  • 事件与 Action 入口：CampaignEvents · CampaignEventReceiver
  • Actions 家族页：编写中 → 见 campaign-ext 模块（KillCharacterAction / ChangeRelationAction / GiveGoldAction / DeclareWarAction 等）
  • 实体：Hero · Clan · Kingdom
  • 风险：见 崩溃边界 · 世界变更须走 Action

3. 加自定义存档字段且不坏档

  • SaveManager
  • SaveableFieldAttribute · SaveablePropertyAttribute
  • CampaignBehaviorBase.SyncData(IDataStore)（行为持久化钩子）
  • IDataStore（读写自定义数据）
  • 风险：见 崩溃边界 · 存档

4. 写 MissionBehavior 并在 Agent 死亡时处理

  • Mission · MissionBehavior
  • Agent · Team · Formation
  • MissionLogic（逻辑聚合）
  • 风险：见 崩溃边界 · Agent/Mission 生命周期

5. 改党派战争得分 / 经济数值

  • GameModels（模型聚合入口）
  • 具体模型（PartySpeed/Wage/Diplomacy/…）页面编写中 → 见 campaign-ext 模块
  • 风险：替换模型要经 GameModels 注册，直接 new 会被覆盖。

6. 做 UI 界面（Gauntlet）

  • ScreenManager · ScreenBase
  • GauntletLayer（加载 movie / 绑定 DataSource）
  • ViewModel 模式 → 见 viewmodel 模块
  • 风险：见 崩溃边界 · UI/ViewModel 寿命

7. 本地化文本

  • TextObject

8. 实体 / 据点相关

  • MobileParty · PartyBase · Settlement · Town · Village · Workshop
  • Clan · Kingdom · Army · MapEvent · SiegeEvent
  • ItemObject · Equipment · ItemRoster · TroopRoster
