Every page is based on the v1.4.5 helper source and real CampaignSystem/StoryMode call sites.

**Tech Stack:** Markdown, Zola clean URLs, Bannerlord v1.4.5 decompiled C# source, Node.js handwritten-page and repository audit scripts.
