# Noise & Non-Business Type Policy

> This site is a **mod-developer handbook**, not a prose expansion of every decompiled symbol.  
> Types below are **intentionally not deep-written**, but must remain findable and must not pretend to be curated API docs.

## One-line job

Define what counts as **noise**, how the site presents it, and which managed APIs readers should return to.

## What counts as noise

| Class | Typical names / assemblies | Why no deep page | Return to |
|------|----------------------------|------------------|-----------|
| Save autogen | `AutoGenerated*`, generated save helpers | Engine-generated; churns by version | [`SaveManager`](../../api/save-system/SaveManager) · [`SaveableTypeDefiner`](../../api/save-system/SaveableTypeDefiner) · [`IDataStore`](../../api/campaign-ext/IDataStore) |
| Third-party | `Newtonsoft.*`, `Steamworks.*`, `Mono.*` | Not TaleWorlds domain semantics | Upstream docs; game logic stays on `TaleWorlds.*` |
| Platform / store | `TaleWorlds.Platform*`, store providers | Channel-specific; rare for gameplay mods | Campaign APIs for world state |
| Native thin wrappers | Many `IMB*` forwards | No extra mental model | Engine / Mission hand-written pages |
| Compiler noise | Empty markers / non-semantic attributes | Read source | Owning business type page |

## Site rules (mandatory)

1. **Inventory-visible** — noise may appear in A–Z / inventory with a noise flag.  
2. **No fake longform** — generators must not invent mental models / method purposes / examples.  
3. **This policy + backlinks** — noise entries should link here or to a module noise note.  
4. **R1 coverage** — noise is **excluded** from the business handwritten denominator, but the exclusion set must be **explicit** in reports (no silent drop).

## When you hit noise

| Situation | You see | Correct move |
|-----------|---------|--------------|
| Decompile save code | `AutoGeneratedInstanceCollect*` | Use `[SaveableField]` / `SyncData` contracts |
| IDE jumps to Steam/JSON | Third-party types | Do not expect business samples here |
| Search `IMBAgent` | Native interface | Read `Agent` / `Mission` instead |
| Login / cloud | Platform services | Index only; world state still Campaign |

## Relation to R1 scope

```
all public types
  ├── business public → handwritten deep page OR family entry
  └── noise (table above) → inventory + this policy
```
