# Core、Library、Engine 平台长尾

## Mental Model

这些身份属于托管基础层。Core 和 Library 提供值对象、序列化与诊断工具；Engine 提供场景、渲染、物理及 Native 桥的托管包装。Mod 应先依赖这些托管入口，不应把 `[EngineMethod]` 或 Native 地址当作稳定 ABI。

## Dependencies

- [Engine](../) 与 [Native Reference](../../../native/) 说明托管/原生边界；持久战役状态仍由 CampaignSystem 拥有。

## Source provenance

类型身份和页面路径来自 `tools/data/type-inventory.json`。Engine 的 Native 关联只通过托管包装器和 `native-1.3.15-src` 证据页追踪；本页不扩展 Native 类海。
