Campaign behavior long-tail family

Campaign behavior long-tail family

Mental Model

This is the long-tail index for official Campaign behavior implementations. CampaignGameStarter registers them; they subscribe to CampaignEvents and persist their own state in SyncData. Read them for call order, not as reusable singletons.

Dependencies

  • CampaignGameStarter, CampaignEvents, and CampaignBehaviorBase define registration and lifecycle.
  • Persistent changes return to Actions; save boundaries are controlled by IDataStore.
