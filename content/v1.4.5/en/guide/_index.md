# Guide

This section collects practical, task-oriented guides for Mount & Blade II: Bannerlord v1.4.5 modding.

> Version 1.4.5 documentation is still being organized. In the meantime, most workflows are identical to v1.3.15; see the [v1.3.15 guide](../../../v1.3.15/en/guide/) for detailed walkthroughs.

## Guide categories

- **Environment setup** — dependencies, module folder layout, loading order
- **Gauntlet UI** — movie, widget, viewmodel and prefab workflow
- **Mission system** — mission logic, agent/formation/team lifecycle
- **Campaign system** — parties, settlements, kingdoms, behaviors, actions
- **Save system** — saveable fields/properties, upgrade migration
- **Asset pipeline** — XMLs, scenes, assets
- **Localization** — text strings, text processor, language files
- **Common patterns** — mod entry points, event hooks, game model overrides
- **Troubleshooting** — crash boundaries, native interop limits

## Where to start

If you are new to Bannerlord modding, start with the [v1.3.15 SDK overview](../../../v1.3.15/en/architecture/sdk-overview/) and the [mod workflow](../../../v1.3.15/en/guide/mod-workflow/) guide; then return here for v1.4.5-specific differences once this section is populated.
